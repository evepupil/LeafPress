# LeafPress 命令速查

以下示例均用 `--json`。成功响应外层为 `{ "ok": true, ... }`；失败为 `{ "ok": false, "error": { "code", "message", "hint?" } }`。账号编号示例写作 `<平台编号>-<序号>`，如 `zhihu-1`、`blog-2`；实际操作一律使用命令返回的编号。

| 命令路径           | 用法                                                                                                                            | JSON 返回里取什么                                                                                                                                                                                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `init`             | `leafpress init --json`                                                                                                         | `home`、`configFile`、`dbFile` 和 `migration`，确认初始化位置与记录库版本。                                                                                                                                                                                                               |
| `doctor`           | `leafpress doctor --json`                                                                                                       | `checks` 中每项的状态和说明；体检不负责修复。                                                                                                                                                                                                                                             |
| `serve`            | `leafpress serve [--port <端口>] [--open] [--dev] --json`                                                                       | `url`；服务启动后进程持续运行。                                                                                                                                                                                                                                                           |
| `works`            | `leafpress works [--status <todo,doing,waiting,done>] [--account <账号编号>] --json`                                            | `works`；`todo` 项按队列顺序，第一项编号在 `works[0].id`。                                                                                                                                                                                                                                |
| `work show`        | `leafpress work show <作品编号> --json`                                                                                         | `detail.context` 是完整作品说明；`detail.work` 是当前状态。                                                                                                                                                                                                                               |
| `work next`        | `leafpress work next [--account <账号编号>] --json`                                                                             | `lease.token` 用于后续推进；完整说明读 `detail.context`。无可接作品时 `detail` 为 `null`。                                                                                                                                                                                                |
| `work start`       | `leafpress work start <作品编号> [--force] --json`                                                                              | `lease.token` 和 `detail.context`；`--force` 用于明确接管已有租约。                                                                                                                                                                                                                       |
| `work step`        | `leafpress work step <作品编号> --lease <令牌> [--force] --json`                                                                | `message`、`detail.context`；停在等作者处理时从上下文取原文转告作者。                                                                                                                                                                                                                     |
| `work run`         | `leafpress work run <作品编号> --lease <令牌> --json`                                                                           | `message`、`outcome.kind` 和 `detail.context`；`outcome.kind` 为 `fail` 时报告原因并停下。                                                                                                                                                                                                |
| `work back`        | `leafpress work back <作品编号> <步骤序号> --lease <令牌> --json`                                                               | `message` 和 `detail.context`；步骤序号从 1 开始。                                                                                                                                                                                                                                        |
| `work release`     | `leafpress work release <作品编号> --lease <令牌> --json`                                                                       | `work`；作品交还到待实现队列。                                                                                                                                                                                                                                                            |
| `work feedback`    | `leafpress work feedback <作品编号> <反馈文字> --json`                                                                          | `work`；提交作者反馈后再接手作品。                                                                                                                                                                                                                                                        |
| `work new`         | `leafpress work new --account <账号编号,…> --title <标题> [--brief <要求>] --json`                                              | `works` 中每个新作品的 `id`。                                                                                                                                                                                                                                                             |
| `convert`          | `leafpress convert <灵感编号或作品编号> --to <账号编号,…> [--brief <要求>] --json`                                              | `works` 中新作品的 `id`；灵感编号以 `i-` 开头。                                                                                                                                                                                                                                           |
| `ideas`            | `leafpress ideas [--status <inbox,promising,converted>] --json`                                                                 | `ideas`，每项含灵感编号、状态和内容。                                                                                                                                                                                                                                                     |
| `ideas add`        | `leafpress ideas add <一句话> --json`；批量：`leafpress ideas add --stdin --json`                                               | `ideas[].id`；批量标准输入是 JSON 数组，每项必填 `text`，可选 `detail`、`accountId`、`source`、`sourceDetail`。                                                                                                                                                                           |
| `accounts`         | `leafpress accounts --json`                                                                                                     | `accounts`，核对账号编号、平台和档案状态。                                                                                                                                                                                                                                                |
| `account show`     | `leafpress account show <账号编号> --json`                                                                                      | `account` 和 `setup`；查看档案全文及接入状态。                                                                                                                                                                                                                                            |
| `account add`      | `leafpress account add --platform <平台> --name <名称> [--intro <一句话>] --json`                                               | `account.id` 是后续命令使用的账号编号。                                                                                                                                                                                                                                                   |
| `account set`      | `leafpress account set <账号编号> <配置项> [值] [--stdin] [--clear] --json`                                                     | `account`；值不带引号地写进命令行，密钥一律用 `--stdin` 从标准输入读；`--clear` 或空值表示清掉。配置项不对时读 `error.hint` 里列出的可用项。成功输出不含值。                                                                                                                              |
| `account import`   | `leafpress account import <账号编号> --json`                                                                                    | `summary`：`added`（新建）、`skipped`（已有）、`drafts`（跳过的草稿）、`issues`（读不了的原稿，每项 `path` 和 `message`）、`works`（新作品，只带 `id`、`title`、`url`、`publishedAt`）。博客导入前要先用 `account set` 配好 `repo-path` 和 `site-url`；知乎导入前要配好 `access-secret`。 |
| `data pull`        | `leafpress data pull [--account <账号编号,…>] --json`                                                                           | 拉一次平台数据；查看 `outcomes` 和 `note`，失败或缺配置时按返回说明处理。                                                                                                                                                                                                                 |
| `data show`        | `leafpress data show [--account <账号编号>] [--range <4w 或 12w>] [--top <个数>] [--by <reach、interactions 或 growth>] --json` | 账号概况、走势和作品排行。`--account` 只能给一个账号，缺省是全部账号；`--range` 只认 `4w`、`12w`，缺省 `12w`；`--by` 只认 `reach`、`interactions`、`growth`，缺省 `reach`；`--top` 缺省 10。字段说明见表后。                                                                              |
| `report`           | `leafpress report [--week <YYYY-MM-DD 格式的周一>] --json`                                                                      | 周报和复盘。`--week` 是 YYYY-MM-DD 格式的周一，只能选最近 9 周，写错会列出可选的周；不填则看昨天所在的那一周，这一周可能还没过完，要看上一整周就用 `--week <上周一>`。字段说明见表后。                                                                                                    |
| `schedule install` | `leafpress schedule install [--at <HH:mm>] --json`                                                                              | 安装或更新每日定时拉取任务；不填时间则使用配置的时间。                                                                                                                                                                                                                                    |
| `schedule remove`  | `leafpress schedule remove --json`                                                                                              | 卸下定时拉取任务。                                                                                                                                                                                                                                                                        |
| `schedule status`  | `leafpress schedule status --json`                                                                                              | 查看定时拉取任务和最近一次运行状态。                                                                                                                                                                                                                                                      |
| `export`           | `leafpress export --json`                                                                                                       | `dir`，即备份导出目录。                                                                                                                                                                                                                                                                   |
| `skill install`    | `leafpress skill install [--force] --json`                                                                                      | `targets` 中每个安装路径及 `action`；覆盖时才加 `--force`。                                                                                                                                                                                                                               |

## 知乎：三条工作流的注意事项

三条工作流由 LeafPress 按来源和要求自动配，agent 不用选：

1. **回答问题**（要求或标题里有知乎问题链接 `zhihu.com/question/…`）：出提纲 → 你确认提纲 → 写回答 → 生成复制页 → 你去回答 → 归档链接。
2. **博客改写**（从博客作品转来）：改写成知乎文章 → 生成复制页 → 你去发布 → 归档链接，没有确认大纲一步。
3. **写文章**（其余）：出大纲 → 你确认大纲 → 写全文 → 生成复制页 → 你去发布 → 归档链接。

- **先确认大纲**：写文章、回答问题的 AI 步骤只做到 `大纲.md` / `提纲.md`（提纲第一行写问题标题和链接），报完这步作品就停在「你确认大纲 / 你确认提纲」等作者。作者反馈要改，先改大纲，再写全文。
- **写作规则在账号档案里**：档案可能只写规则文件的位置，先整份读档案，照那份写；交稿前按它的自检清单逐条过一遍。
- **稿子格式**：文章存 `文章.md`，第一行是 `# 标题`；回答存 `回答.md`，不写标题，第一行就是正文；流程图用 mermaid 代码块；图片照博客原来的写法，或放进任务文件夹。
- **复制页不用自己写**：`知乎发布稿.html` 由「生成复制页」代码步骤生成（转 HTML、补站内链接、内嵌图片）。之后作品停在「你去发布 / 你去回答」，作者发完把链接贴回来，「归档链接」会认知乎的文章链接（`zhuanlan.zhihu.com/p/…`）和回答链接（`zhihu.com/question/…/answer/…`）。
- **账号接入**：知乎拉数据、导已发内容要配开放平台密钥（`access-secret`）。帮作者配用 `leafpress account set <账号> access-secret --stdin`，密钥从标准输入读，不写进命令行。已发的文章、回答用 `leafpress account import <知乎账号> --json` 导入为作品。
- **拉数据**：每天最多用 90 次开放平台额度，一天只拉一次；`data pull` 返回「已是最新」属正常，不是失败。

## 查数据：JSON 里看什么

先分清「没有」和「0」，补出来的 0 不是真实的 0。

- `interactions`、`interactions7d` 是每个账号的「第二个数」：知乎是互动（点赞、收藏、评论、分享加起来），博客没有互动，是访客。看每个账号的 `secondaryLabel`；几个账号的合计只加互动。
- 粉丝是 `null`，表示这个平台拿不到粉丝数（博客拿不到订阅数），不是 0，不要写成「0 个订阅」。涉及的字段：`data show` 的 `summaries[].followers`、`followers7d`、`followers30d`、`weeklyGain` 和 `series.followers`；`report` 的 `rows[].followersStart`、`followersEnd`、`delta` 和 `totals.delta`。
- `summaries[].hasData`、`rows[].hasData` 为 false，表示还没拉到过这个账号的数据，它的浏览、互动是补出来的 0。发布篇数（`postsThisWeek`、`posts`）是真的：发了作品就算发布，不管有没有数据。`data show` 里选中的账号都没有数据时，顶层 `hasData` 为 false，也没有 `series` 和 `top`。
- `summaries[].dataThrough` 是记录库里这个账号真正有数的最后一天（拉到了但数是 0 也算），窗口里没有记录为 `null`。它比顶层 `latestDay` 早，说明最近几天没拉到，那几天的 0 是补出来的，不是下滑。
- 走势 `series.<指标>.points` 里每个点是 `{ label, start, end, value, compare }`：`start` 到 `end` 是这个点覆盖的日期（`4w` 按天，两者相同；`12w` 按周，最后一周没过完时 `end` 是数据的最后一天），`value` 是这段的值，`compare` 是上一期同一段的值（`4w` 比 28 天前，`12w` 比 12 周前）。
- 周报的 `report.complete` 为 false，表示这一周还没过完，只统计到 `report.end`；人看的输出里，标题会写「到 X」。
- 账号只带 `id`、`name`、`platform`；作品只带 `id`、`title`、`url`、`publishedAt`。要看档案全文用 `account show`，要看作品全文用 `work show`。
