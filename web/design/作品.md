# 作品 `/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件、状态、推进规则都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label`、按钮文字的地方，交互检查会用到，**名字和取值不能改**。

本页是首页，也是任务管理的地方：**一个作品就是一条任务**。四列从左到右是 AI 的待做 → AI 在做 → 等你做 → 做完了。
本页节奏：视图栏（标题、看板 / 列表、两个动作）→ 筛选栏（平台、搜索、视图条件）→ 看板四列（`bg-column` 列里放白卡，桌面四列铺满，手机横向滑）或列表 → 右侧滑出的详情抽屉。
本页核心动作：①「等你处理」的卡片点开，照着「要你做的事」做完，在反馈框写一句提交；② 待实现里拖动排先后，或者「让 AI 做」。
本页最重要的区块：W2 详情抽屉里的「等你处理」面板，其次是 W1 的卡片。

两路分工：**L1 写 W1**（`works-page.tsx` 和 `works-*.tsx`），**L2 写 W2**（`work-sheet.tsx` 和 `work-sheet-*.tsx`）。L1 只通过下面这个签名用 W2（主控已放了同签名的占位，L2 换成实现）：

```tsx
// src/features/works/work-sheet.tsx
export function WorkSheet({ workId, onClose, onConvert }: {
  workId: string | null          // 为空时关着
  onClose: () => void            // L1 在这里去掉地址栏的 open 参数
  onConvert: (work: Work) => void // L1 在这里打开 ConvertDialog（source 为 { kind: "work", work }）
}): JSX.Element
```

## W1 作品工作区 `src/features/works/works-page.tsx`（`"use client"`，L1）

**外层**：组件直接返回 `<PageFrame …>`，内容区里是 `<section id="works" aria-label="作品" className="h-full">`。
允许拆：`works-board.tsx`（看板）、`works-card.tsx`（卡片）、`works-card-menu.tsx`（卡片菜单）、`works-list.tsx`（列表）、`works-filters.tsx`（筛选栏）、`works-model.ts`（纯函数，可配单测 `works-model.test.ts`）。

### 状态

```ts
view: "board" | "list"           // 默认 board，地址栏 view=list 时为 list
platform: "all" | PlatformId     // 默认 all，地址栏 platform=
query: string                    // 默认 ""，只在本页状态里，不进地址栏
status: WorkStatus | null        // 地址栏 status=（侧栏视图「等你处理」「待实现」用）；为 null 时四列都显示
convertSource: ConvertSource | null   // 打开的转作品弹窗
deleting: Work | null            // 待确认删除的作品
```

`openId` 不放状态，直接读地址栏 `open` 参数。
读参数：`useSearchParams()`；参数变化时用 DESIGN.md 第 7 章的「渲染时对比上一次的参数」写法同步 `view`、`platform`、`status`（不在 effect 里 setState）。
改参数统一一个函数 `setParam(name, value | null)`：基于当前参数改一项，`router.replace(\`/?${search}\`)`（没有参数时 `router.replace("/")`），`{ scroll: false }`。点开卡片 = `setParam("open", id)`；关抽屉 = `setParam("open", null)`；切看板 / 列表、切平台、清掉视图条件都走它（`view=board`、`platform=all` 时删掉参数，不写默认值）。

数据：`const works = useWorks((s) => s.works)`、`const running = useWorks((s) => s.running)`；`const visible = useMemo(() => filterWorks(works, { platform, query }), [works, platform, query])`；每列 `sortColumn(visible, status)`。

### 视图栏（`PageFrame` 的参数）

- `title="作品"`；`meta`：`<span className="tabular" data-works-count>{visible.length}</span>`（初始 64）
- `tabs={[{ key: "board", label: "看板" }, { key: "list", label: "列表" }]}`、`activeTab={view}`、`onTabChange`
- `actions`（从左到右）：
  1. `<Button variant="outline" size="sm" data-pick-next>`，图标 `Bot`，文字「让 AI 挑一个做」（`hidden sm:inline` 包文字，手机只剩图标，按钮 `aria-label="让 AI 挑一个做"`）。点了：`const next = pickNext(works)`；没有 → `toast("待实现里没有能直接做的")`；有 → `runAi(next.id)`，`setParam("open", next.id)`，`toast(\`AI 开始做《${next.title}》\`)`。
  2. `<Button size="sm" data-new-work>`，图标 `Plus`，文字「新建作品」（同样手机只剩图标）。点了：`useUi.getState().setNewWorkOpen(true)`。

### 筛选栏（`filterBar`，用 `FilterBar`）

`left`，从左到右：
1. 平台 `Segmented`（`label="平台"`，根元素包一层 `<div data-works-platform>`）：选项「全部 64」「博客 40」「知乎 22」「B站 1」「小红书 1」——数字是**按当前搜索词筛过、不按平台筛**的个数（随页面变化）。值为 `"all" | PlatformId`。
2. 搜索框：`<div className="relative">` + `Search` 图标（`pointer-events-none absolute top-1/2 left-2 size-3.5 -translate-y-1/2 text-fg-3`）+ `<Input data-works-search aria-label="搜标题、要求、编号" placeholder="搜标题、要求、编号" className="h-6 w-44 pl-7 text-xs" />`。
3. `status` 不为空时：一个视图条件小标签 `<LabelChip data-works-status-chip>` 写「只看：等你处理」（文字取 `WORK_STATUS_LABEL`），后面一个 `IconButton size="icon-xs" label="看全部"`（`X` 图标），点了 `setParam("status", null)`。

`right`：无。

外层 `<div className="scroll-thin flex h-full min-h-0 items-start gap-(--gap-card) overflow-x-auto p-3 pb-20 lg:pb-3 max-md:snap-x max-md:snap-mandatory">`（照 DeverDesk `TasksBoard`）。
四列按 `WORK_STATUS_ORDER`（todo、doing、waiting、done）；`status` 不为空时只显示那一列。每列外层 `<div {...dropProps} data-board-column={status} className="flex max-h-full w-[288px] shrink-0 snap-start xl:w-auto xl:min-w-[240px] xl:flex-1">`，里面 `BoardColumn`：

| 列 | `icon` | `title` | `count` | `actions` |
|---|---|---|---|---|
| todo | `<WorkStatusIcon status="todo" />` | 待实现 | 个数 | `IconButton size="icon-xs" label="新建作品"`（`Plus`，打开新建弹窗） |
| doing | `<WorkStatusIcon status="doing" />` | 进行中 | 个数 | — |
| waiting | `<WorkStatusIcon status="waiting" />` | 等你处理 | 个数 | — |
| done | `<WorkStatusIcon status="done" />` | 已完成 | 个数 | — |

`BoardColumn` 的 `className="max-h-full w-full"`、`bodyClassName="scroll-thin overflow-y-auto"`；拖到上方时加 `outline-2 outline-offset-[-2px] outline-dashed outline-line-3`。

- **已完成**一列默认只放前 20 张卡，下面一个按钮「再显示 20 个」（照 DeverDesk「更多」按钮：`h-8 shrink-0 rounded-md text-sm text-fg-2 hover:bg-hover hover:text-fg` + `focusRing`，`data-show-more`），每点一次多 20 个。
- **空列**：`<p className="px-2 pb-2 text-sm text-fg-2">这一列是空的</p>`；等你处理一列空时写「没有等你处理的作品」。
- **拖动**：`useBoardDrop(WORK_DRAG, (id, beforeId) => { const result = drop(id, status, beforeId); if (!result.ok) toast(result.reason) })`。`over` 时在 `beforeId` 那张卡前面（为空在最后一张卡后面）画 `<DropLine />`。拖到「进行中」就是让 AI 做；拖到「已完成」当作你自己做完了；已完成的卡片不能拖（`draggable={false}`）。
- 手机（`max-md`）浏览器不支持拖动，卡片菜单里有对应的动作。

### 卡片 `works-card.tsx` —— 本页第二重要

照 DeverDesk `TaskCard` 的三层结构。外层：

```tsx
<div
  data-drag-id={work.id} data-work-card={work.id} data-status={work.status}
  draggable={work.status !== "done"} onDragStart={…startCardDrag(e, WORK_DRAG, work.id)…} onDragEnd={endCardDrag}
  onClick={() => onOpen(work.id)}
  className={cn(
    "group flex w-full min-w-0 cursor-pointer flex-col gap-1.5 rounded-lg border border-line bg-card px-3 py-2.5 text-left shadow-sm transition-[border-color,box-shadow,opacity] duration-(--dur-fast) hover:border-line-3",
    work.status === "waiting" && "border-progress/40 hover:border-progress/70",
    work.status !== "done" && "active:cursor-grabbing",
  )}
>
```

拖动中这张卡 `opacity-50`（`onDragStart` 时 set 一个本地 `dragging` 状态，`onDragEnd` 清掉）。

**第一行**（`flex h-[18px] min-w-0 items-center gap-2 text-xs text-fg-2`）：
- `<AccountTag account={…} />`（平台标识 + 账号名）
- 右侧 `ml-auto` 一组：卡片菜单按钮（悬停才出现：`opacity-0 group-hover:opacity-100 group-focus-within:opacity-100 max-lg:opacity-100`）+ 一个时间小字（`tabular shrink-0`）：todo 显示「#1」「#2」……（在待实现一列里的排队位置，从 1 开始，`data-queue-pos`）；doing、waiting 显示 `formatRelative(updatedAt)`；done 显示 `formatDayShort(publishedAt)`（没有就不显示）。

**第二行**：标题按钮 `<button type="button" className="line-clamp-2 min-w-0 text-left text-sm text-fg" title={work.title} onClick={(e) => { e.stopPropagation(); onOpen(work.id) }}>`，加 `focusRing`。已完成的标题 `text-fg`（不变灰）。

**第三行**按状态（`flex min-w-0 flex-wrap items-center gap-1`）：

| 状态 | 内容 |
|---|---|
| todo | `LabelChip`（icon `Workflow` `size-3.5 text-fg-3`）工作流名；有 `feedback` 时再加 `<LabelChip color="amber" data-feedback-chip>你已反馈</LabelChip>`；工作流需配置时再加 `<LabelChip color="amber">要配置</LabelChip>` |
| doing | `running` 里有它：`<Spinner />` + `<span className="truncate text-xs text-fg-2">{progressText(work)}</span>`；没有（外面的 agent 在做）：`<WorkStatusIcon status="doing" />` + 同样的进度文字 |
| waiting | `<Hand className="size-3.5 shrink-0 text-warn" aria-hidden />` + `<span className="truncate text-xs text-warn" data-waiting-step>{waitingLabel(work)}</span>`；右侧 `ml-auto` 一个小按钮 `<Button size="xs" variant="outline" data-handle>去处理</Button>`（点了 `onOpen`，`stopPropagation`） |
| done | 有 `totals`：`Eye` 图标 + `metricText(work, "reads")`，再 `ThumbsUp` 图标 + 互动合计（赞同 + 收藏 + 评论，`formatCount`；博客只有评论，用 `MessageSquare` 图标 + 评论数）；没有 `totals`：`<span className="text-xs text-fg-2">还没有数据</span>` |

第三行图标统一 `size-3.5 text-fg-3`，数字 `text-xs text-fg-2 tabular`。

**来源标记**：来源是作品（`source.kind === "work"`）的卡片，第一行账号名后面加 `<span className="truncate text-fg-3">· 由{来源平台名}转</span>`（例：「· 由博客转」）；来源是灵感的加「· 来自灵感」。

### 卡片菜单 `works-card-menu.tsx`

`DropdownMenu`，触发器 `IconButton size="icon-xs" label="更多"`（`Ellipsis` 图标，`data-card-menu`，点击 `stopPropagation`）。菜单项按状态（`DropdownMenuItem` + 图标），选中后都 `stopPropagation`：

| 状态 | 菜单项（从上到下） |
|---|---|
| todo | 「让 AI 做」(`Bot`) · 「排到最前」(`ChevronUp`，`drop(id, "todo", 第一张卡的编号)`) · 「挪到等你处理」(`Hand`) · 「标记完成」(`CircleCheck`) · 分隔线 · 「删除」(`Trash2`，`variant="destructive"`) |
| doing | 「挪回待实现」(`RotateCcw`) · 「挪到等你处理」 · 「标记完成」 · 分隔线 · 「删除」 |
| waiting | 「去处理」(`Hand`，打开详情) · 「挪回待实现」 · 「标记完成」 · 分隔线 · 「删除」 |
| done | 「转作品」(`Repeat`，`onConvert(work)`) · 「打开链接」(`ExternalLink`，有 `url` 才有，站外新窗口) · 分隔线 · 「删除」 |

「让 AI 做」：`const r = runAi(id); if (!r.ok) toast(r.reason)`。挪列都走 `drop(id, 目标状态, null)`，失败 toast `reason`。
「删除」：设 `deleting`，弹 `ConfirmDialog`（`title={\`删除《${shortTitle(work.title)}》？\`}`、`confirmLabel="删除"`、`destructive`），确认后 `remove(id)`、关掉详情（如果开着的就是它）、`toast("已删除")`。

### 详情和弹窗的挂载

`works-page.tsx` 里挂：`<WorkSheet workId={openId} onClose={() => setParam("open", null)} onConvert={(work) => setConvertSource({ kind: "work", work })} />`、`<ConvertDialog source={convertSource} onClose={() => setConvertSource(null)} />`、删除用的 `ConfirmDialog`。

### 状态与响应式

- 加载：静态导出首屏就是初始数据，没有加载态；`StoreHydration` 挂载后可能换成浏览器里存的数据，不闪烁处理。
- 错误：所有失败都是 `ActionResult`，toast 原因。
- 手机：看板横向滑，每列 288px、`snap-start`；视图栏两个按钮只剩图标；筛选栏横向可滚（`FilterBar` 已处理）。
- 长标题：卡片两行截断，列表一行截断，`title` 属性给全文。

## W2 作品详情抽屉 `src/features/works/work-sheet.tsx`（`"use client"`，L2）—— 本页最重要

签名见本文件开头。允许拆：`work-sheet-waiting.tsx`（等你处理面板）、`work-sheet-fields.tsx`（属性行）、`work-sheet-steps.tsx`（步骤）、`work-sheet-folder.tsx`（任务文件夹）、`work-sheet-log.tsx`（记录）、`work-sheet-stats.tsx`（数据）。

**外层**：`<Sheet open={workId !== null && work !== undefined} onOpenChange={(open) => !open && onClose()}>` + `<SheetContent side="right" className="w-full gap-0 p-0 data-[side=right]:sm:max-w-[560px]" onInteractOutside={ignoreToastInteraction}>`（`ignoreToastInteraction` 来自 `@/lib/toast`）。
`const work = useWorks((s) => s.works.find((w) => w.id === workId))`——**这里返回的是数组里已有的对象，可以直接用选择器**。`workId` 有值但找不到（被删了、编号写错）：抽屉不打开，并调用一次 `onClose()`（用「渲染时对比」写法或在点击处理里处理，不要在 effect 里 setState；最简单：`open` 只看 `work !== undefined`，找不到时什么都不渲染）。

整体：顶部固定的头（标题区），下面一个可滚动的主体（`scroll-thin flex-1 overflow-y-auto`），主体里各段之间 `border-t border-line`，每段 `px-4 py-3`。

### 头 `data-sheet-header`

- 第一行（`flex h-10 items-center gap-2 border-b border-line px-4 pr-12`，右边给关闭按钮留位）：`WorkStatusIcon` + 状态名（`text-xs text-fg-2`）+ `·` + `AccountTag account showPlatform` + 编号 `<span className="ml-auto font-mono text-xs text-fg-2" data-work-id>{work.id}</span>`。
- `SheetTitle` 放标题输入框：`<Input id="work-title" aria-label="标题" value={draft} … className="h-auto border-transparent px-0 text-sm font-medium shadow-none hover:border-line-2 focus-visible:border-line-3" />`，外面 `px-4 pt-3`。失焦或回车时，内容去掉首尾空格后非空且有变化才 `update(id, { title })`；清空了就还原。`SheetDescription` 用 `sr-only` 写「作品详情」。
- 动作行（`flex flex-wrap items-center gap-1.5 px-4 pt-2 pb-3`）：
  1. 「让 AI 做」`<Button size="sm" data-run-ai>`（`Bot`）：status 为 todo 或 doing 时显示。`running` 里有它时变成禁用的 `<Spinner /> AI 在做`；doing 但不在 `running`（外面的 agent 在做）时文字为「接着做」；todo 且有 `feedback` 时文字为「让 AI 继续」。点击 `runAi(id)`，失败 toast `reason`。工作流需配置时按钮照常可点（会 toast `setupHint`）。
  2. 「复制给 AI」`<Button size="sm" variant="outline" data-copy-context>`（`Copy`）：`copyText(taskContext(work, sourceInfo))`，成功 `toast.success("已复制，粘贴给任意 agent 就能接着做")`，失败 `toast("浏览器不让写剪贴板")`。`sourceInfo`：来源是作品时取那个作品的 `{ title, url, localPath }`；来源是灵感时取 `{ title: 灵感 text }`；导入的博客取自己的 `{ title, url, localPath }`；其余不传。
  3. 「转作品」`<Button size="sm" variant="outline" data-convert>`（`Repeat`）：只在 done 时显示，点了 `onConvert(work)`。
  4. 右侧 `ml-auto` 一个 `IconButton label="删除" size="icon-sm"`（`Trash2`）：`ConfirmDialog` 确认后 `remove(id)`、`onClose()`、`toast("已删除")`。

### ① 等你处理面板 `work-sheet-waiting.tsx`（只在 status 为 waiting 时，放在主体最上面）—— 全站最重要

这是**通用**的面板：不管哪个工作流、哪一步要你动手，长得都一样，内容全来自 `work.ask`。

```
┌──────────────────────────────────────────────┐
│ ✋ 要你做的事 · 你去知乎投递                    │   第 6/7 步
│ 用浏览器打开 ~/.leafpress/tasks/z-design-…/复制页.html，│
│ 点「复制正文」，到知乎「写文章」粘贴后发布。发布后把文章链接填在下面。│
│ [📁 ~/.leafpress/tasks/z-design-extraction  ⧉]  │
│ ┌──────────────────────────────────────────┐ │
│ │ 做完了写在这里，例如：发布了，链接是 https://… │ │
│ └──────────────────────────────────────────┘ │
│                                  [提交反馈]   │
└──────────────────────────────────────────────┘
```

- 外层 `<section aria-label="要你做的事" data-waiting-panel className="m-4 rounded-lg border border-progress/40 bg-card p-3 shadow-sm">`。
- 标题行：`Hand`（`size-4 text-warn`）+ `<h3 className="text-sm font-medium">要你做的事</h3>` + `<span className="truncate text-sm text-fg-2">· {waitingLabel(work)}</span>` + 右侧 `ml-auto text-xs text-fg-2 tabular` 写 `第 ${step + 1}/${总步数} 步`。
- 正文：`<p className="mt-2 text-sm whitespace-pre-wrap" data-ask>{work.ask}</p>`。
- 任务文件夹一行：`mt-2 flex items-center gap-1.5 rounded-md bg-raised px-2 py-1` + `FolderOpen` 图标 + `<span className="min-w-0 flex-1 truncate font-mono text-xs">{taskFolder(id)}</span>` + `IconButton size="icon-xs" label="复制路径"`（`Copy`，复制后 `toast.success("已复制")`）。
- 反馈框：`<Textarea id="work-feedback" aria-label="你的反馈" rows={3} placeholder="做完了写在这里，例如：发布了，链接是 https://…" className="mt-3" />`，⌘/Ctrl + 回车提交（输入法选词时不算）。
- 底部右对齐：`<Button size="sm" data-submit-feedback disabled={!text.trim()}>提交反馈</Button>`。

### ⑨ 记录 `work-sheet-log.tsx`

### 状态

- 抽屉打开时 `work` 在 store 里变化（AI 一步步走），整个抽屉实时跟着变：步骤图标、进度、面板出现 / 消失。
- 输入框的草稿：标题、要求、问题、链接都是「本地草稿 + 失焦保存」。换了一个作品（`workId` 变了）草稿要重置：草稿组件用 `key={work.id}` 包起来。
- 手机：抽屉全宽，各段照常；两列属性网格不变（左列 88px）。
