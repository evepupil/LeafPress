# 作品 `/works/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label`、按钮文字的地方，交互检查会用到，**名字和取值不能改**。

本页节奏：视图栏（标题 + 看板/列表页签 + 新作品按钮）→ 筛选栏 → 看板四列（`bg-column` 列里放白卡）或白底表格 → 右侧滑出的详情抽屉。
本页核心动作：在看板里点开一个作品，看它在各平台的版本和数据。
本页最重要的区块：W1 就是整页，看板卡片和详情抽屉是重点。

整页只有一个区块 `WorksWorkspace`，因为视图栏、筛选栏、看板、列表、抽屉共用同一份状态。允许拆子组件：只能新建为 `src/features/works/works-workspace-*.tsx`（例如 `works-workspace-board.tsx`、`-table.tsx`、`-sheet.tsx`、`-filters.tsx`、`-new-dialog.tsx`），状态放在主文件往下传。

## W1 作品工作区 `src/features/works/works-workspace.tsx`（`"use client"`）

**外层**：组件直接返回 `<PageFrame …>`（`@/features/shell/page-frame`），内容区里是 `<section id="works" aria-label="作品">`。

### 状态（全部放在主文件）

```ts
view: "board" | "list"                         // 默认 "board"
query: string                                  // 搜索词，默认 ""
account: string                                // "all" 或账号编号，默认 "all"
platform: "all" | PlatformId                   // 默认 "all"
status: "all" | WorkStatus                     // 默认 "all"
pendingOnly: boolean                           // 只看待发，默认 false
sort: { key: "first" | "reads" | "growth"; dir: "desc" | "asc" } | null   // 列表排序，默认 null（按最近更新）
showAllPublished: boolean                      // 看板「已发」列是否展开全部，默认 false
openId: string | null                          // 详情抽屉打开的作品
rows: WorkRow[]                                // 初始为 WORK_ROWS，新建作品时往最前面加
pubOverrides: Record<string, { state: "published"; url: string }>   // 回填链接后的覆盖
```

读地址栏参数（`useSearchParams`）。首次渲染就按参数初始化，之后参数变化时也跟着变（侧栏「待发」、命令面板选作品都会在本页改地址，页面不会重新挂载），用「根据输入变化调整状态」的写法，不在 effect 里 setState；参数里没有的项不清空已有筛选：`open=<作品编号>` → 打开抽屉；`view=pending` → `pendingOnly = true`；`account=<账号编号>` → `account` 设为它。关闭抽屉时用 `router.replace("/works/")` 去掉 `open` 参数（其余参数一起去掉）。

### 筛选规则

一个作品留下的条件（同时满足）：
- `query`：标题包含搜索词（忽略大小写，去掉首尾空格后为空则不筛）
- `account`：作品主账号是它，**或**它有任何一个版本在这个账号上
- `platform`：它有任何一个版本在这个平台上
- `status`：作品状态相等
- `pendingOnly`：作品状态为 ready，或有任何一个版本的状态（含覆盖）是 scheduled / pending-link

当前数据下：搜「Cloudflare」剩 10 个；只看待发剩 4 个（Jev、AI 做的页面、Cloudflare Tunnel 加 Access、SaaS 后台）。

### 视图栏（`PageFrame` 的参数）

- `title="作品"`
- `meta`：`<span className="tabular" data-works-count>{筛选后的个数}</span>`（初始 49）
- `tabs={[{ key: "board", label: "看板" }, { key: "list", label: "列表" }]}`、`activeTab={view}`、`onTabChange`
- `actions`：`<Button variant="outline" size="sm" onClick={打开新建弹窗}><Plus />新作品</Button>`

### 筛选栏（`PageFrame` 的 `filterBar`，用 `FilterBar`）

`left`，从左到右：
1. 搜索框：`<div className="relative">` + `<Search className="pointer-events-none absolute top-1/2 left-2 size-3.5 -translate-y-1/2 text-fg-3" aria-hidden />` + `<Input data-works-search aria-label="搜标题" placeholder="搜标题" value={query} onChange={…} className="h-6 w-44 pl-7 text-xs" />`
2. 账号 `Select`（触发器 `h-6 w-auto gap-1 text-xs`，`data-works-account`）：「全部账号」+ 5 个账号（选项里显示 `PlatformMark` + 名字 +「· 平台名」）
3. 平台 `Select`（`data-works-platform`）：「全部平台」+ 博客、知乎、公众号、B站、小红书
4. 状态 `Select`（`data-works-status`）：「全部状态」+ 灵感、在写、待发、已发
5. 只看待发：`<button type="button" aria-pressed={pendingOnly} data-works-pending className={…}>`，类名用对象映射：共用 `inline-flex h-6 shrink-0 items-center gap-1 rounded-md border px-2 text-xs transition-colors duration-(--dur-fast)` + `focusRing`；按下时 `border-line-3 bg-selected text-fg`，否则 `border-line-2 bg-card text-fg-2 hover:text-fg`；内容 `<StatusIcon glyph="dot" tone="progress" size={12} />` + 「只看待发」

`right`：有任何筛选生效时显示 `<Button variant="ghost" size="sm" onClick={全部重置}>清除筛选</Button>`。

### 看板视图（`view === "board"`）

容器 `<div className="grid items-start gap-(--gap-card) p-3 pb-20 md:grid-cols-2 lg:pb-3 xl:grid-cols-4">`，四列按 `WORK_STATUS_ORDER`（灵感、在写、待发、已发）：
`<BoardColumn icon={<WorkStatusIcon status={s} />} title={WORK_STATUS_LABEL[s]} count={该列个数} className="min-w-0">`

每列的卡片按 `rows` 原有顺序（最近更新在前）。「已发」列在 `showAllPublished` 为假时只显示前 12 张，后面跟一个
`<CollapsedRow data-works-more label={`更早的 ${剩余数} 篇`} onClick={() => setShowAllPublished(true)} />`（当前数据 43 篇，显示 12，按钮文字「更早的 31 篇」）；展开后按钮消失。

作品卡片：
`<button type="button" data-work-card={row.work.id} onClick={() => setOpenId(row.work.id)} className={cn("flex w-full min-w-0 flex-col gap-1.5 rounded-lg border border-line bg-card px-3 py-2.5 text-left shadow-sm transition-[border-color] duration-(--dur-fast) hover:border-line-3", focusRing)}>`
1. 第一行 `flex min-w-0 items-center gap-1.5 text-xs text-fg-2`：栏目 `<ColorDot color={栏目色} />` + `<span className="truncate">{栏目名}</span>`（栏目用 `columnOf(work.accountId, work.columnId)`）+ 右边 `ml-auto shrink-0 tabular` 的 `formatDay(work.updatedAt)`
2. 标题 `<span className="line-clamp-2 text-sm font-medium">{work.title}</span>`
3. 版本 `<div className="flex flex-wrap gap-1">`：每个版本一个 `<PubChip pub={含覆盖后的版本} />`，排序：published 在前，其余按 pending-link、scheduled、draft；没有版本时放 `<LabelChip>还没有版本</LabelChip>`
4. 数据（只在 `row.reads > 0` 时显示）`flex items-center gap-3 text-xs text-fg-2 tabular`：`<Eye className="size-3" aria-hidden />` + `formatCount(row.reads)`；`<ThumbsUp className="size-3" aria-hidden />` + `formatCount(row.interactions)`；`row.growth > 0` 时 `<TrendingUp className="size-3" aria-hidden />` + `+{formatCount(row.growth)}`

列为空时列里放一行 `<p className="px-2 py-3 text-xs text-fg-2">没有作品</p>`。

### 列表视图（`view === "list"`）

容器 `<div className="p-3 pb-20 lg:pb-3">` 里一张 `<Surface className="overflow-hidden">`，表格外包 `<div className="overflow-x-auto">`，`<table className="w-full min-w-[880px] text-sm">`：

| 列 | 表头 | 单元格 |
|---|---|---|
| 标题 | 「作品」 | `<div className="flex min-w-0 max-w-[360px] items-center gap-2">` + `<WorkStatusIcon status />` + `<span className="truncate">{title}</span>` |
| 栏目 | 「栏目」 | `ColorDot` + 栏目名，`text-xs text-fg-2` |
| 版本 | 「版本」 | 最多 3 个 `PubChip`，多出来的显示 `<span className="text-xs text-fg-2">+N</span>` |
| 首发 | 「首发」（可排序） | `firstPublishedAt ? formatDay(...) : "—"`，`tabular text-fg-2` |
| 阅读 | 「阅读」（可排序） | `formatCount(reads)`，`tabular`，0 显示 `—` |
| 互动 | 「互动」 | `formatCount(interactions)`，`tabular text-fg-2`，0 显示 `—` |
| 近 7 天 | 「近 7 天」（可排序） | `growth > 0 ? "+" + formatCount(growth) : "—"`，`tabular` |

- 表头 `<thead className="bg-raised text-xs text-fg-2">`，`th` 为 `h-8 px-3 text-left font-normal`，数字列 `text-right`。
- 可排序的表头里放 `<button type="button" data-sort={key} className="inline-flex items-center gap-1 hover:text-fg">{文字}<ArrowUpDown className="size-3" aria-hidden /></button>`，`th` 带 `aria-sort`（`ascending` / `descending` / `none`）。点一次按这一列倒序，再点改正序，点第三次取消排序（回到最近更新顺序）。「首发」为空的排在最后。
- 行 `<tr data-work-row={work.id} onClick={打开抽屉} className="h-9 cursor-default border-t border-line hover:bg-hover">`；第一列的标题文字外面再包一个 `<button type="button" className={focusRing}>` 方便键盘打开。

### 详情抽屉（`openId` 不为空时）

`<Sheet open onOpenChange={(open) => !open && 关闭}>`，`<SheetContent side="right" className="gap-0 p-0 data-[side=right]:w-full data-[side=right]:sm:max-w-[560px]" data-work-sheet>`（抽屉组件自带的宽度写在 `data-[side=right]` 前缀下，优先级更高，覆盖时要带同样的前缀）：

1. 头部 `border-b border-line px-4 py-3`：
   - 第一行 `flex items-center gap-2 text-xs text-fg-2`：`<WorkStatusIcon status />` + `WORK_STATUS_LABEL` + 「·」+ `<ColorDot />` 栏目名
   - `<SheetTitle className="mt-1 text-sm font-medium" data-work-sheet-title>{work.title}</SheetTitle>`（可换行）
   - 第三行 `mt-1 flex flex-wrap items-center gap-2 text-xs text-fg-2`：`<AccountTag account={主账号} showPlatform />` + `创建于 {formatDay(createdAt)}`
2. 内容 `scroll-thin flex-1 overflow-y-auto px-4 py-3`，分四节，每节标题 `<h3 className="pb-1.5 text-xs font-medium text-fg-2">`：
   - **各平台版本**：每个版本一块 `<div data-pub-row={pub.id} className="flex flex-col gap-1.5 border-b border-line py-2.5 last:border-b-0">`
     - 第一行 `flex items-center gap-2`：`<PlatformMark platform size={16} />` + `<span className="text-sm">{平台名}{形态不是 article 时加 PUB_FORMAT_LABEL}</span>` + `<span className="text-xs text-fg-2">{账号名}</span>` + 右边 `ml-auto` 状态：published → `formatDay(publishedAt)`（`text-xs text-fg-2 tabular`）+ `IconButton`（label「打开链接」，`ExternalLink`，点了 `window.open(url, "_blank", "noreferrer")`）+ `IconButton`（label「复制链接」，`Copy`，`copyText(url)` 成功后 `toast.success("已复制")`）；pending-link → `<Button size="sm" variant="outline" data-backfill-open>回填链接</Button>`；scheduled → `<span className="text-xs text-fg-2">计划 {formatDay(plannedFor)}</span>`；draft → `<LabelChip>草稿</LabelChip>`
     - 回答：第二行 `text-xs text-fg-2`「回答：{question}」
     - published 时数据行 `grid grid-cols-4 gap-2 text-xs`：四格「阅读」「赞同」「收藏」「评论」，标签 `text-fg-2`，值 `text-sm tabular`，值用 `metricText(pub, key)`（博客的赞同、收藏显示「—」）；每格加 `data-pub-metric={key}`
     - 点了「回填链接」后，按钮位置下面出现一行 `<form className="flex gap-1.5">`：`<Input data-backfill-input aria-label="粘贴链接" placeholder="粘贴发布后的链接" className="h-7" />` + `<Button type="submit" size="sm" data-backfill-submit>登记</Button>`；输入为空时按钮禁用；提交后 `pubOverrides[pub.id] = { state: "published", url }`，这个版本按已发显示（发布日期显示「今天」用 `formatDay(TODAY)`，数据四格显示「—」），`toast.success("已登记，知乎版本改为已发")`
   - **近 14 天阅读**：把这个作品所有已发版本的 `pubDaily(pub)`（`@/data/series`）按天相加，取 `LATEST_DAY` 往前 14 天（含），做成 `BarDatum[]`（`label` 为 `formatDayShort`，`title` 为 `${formatDay(day)} · ${formatCount(reads)}`），用 `<LabeledBars data={…} height={72} />`；全是 0 时显示 `<p className="text-sm text-fg-2">还没有阅读数据</p>`
   - **来源**：`dl` 两列网格 `grid grid-cols-[72px_1fr] gap-x-3 gap-y-1.5 text-sm`：「原稿」→ `sourceRef` 用 `font-mono text-xs`，没有就「—」；「写在」→ origin 映射（notion「Notion 同步」、repo「博客仓库」、zhihu-writing「知乎写作」、pipeline「自动流程」、idea「灵感」）；「篇幅」→ `${formatCount(words)} 字 · ${images} 张图 · ${codeBlocks} 段代码`（缺哪项就省掉哪项，全缺则「—」）；有 `runId` 时「工具」→ `<Link href={`/tools/?run=${runId}`}>` 文字 `${toolName(run.toolId)} · ${RUN_STATE_LABEL[run.state]}`（运行从 `RUNS` 里按编号找）
   - **备注**：有 `note` 时 `<p className="rounded-md bg-raised px-3 py-2 text-sm">`；没有就不显示这一节
3. 底部 `flex gap-2 border-t border-line px-4 py-3`：`<Button variant="outline" size="sm">` 复制标题（`Copy` 图标，`copyText(title)` 后 toast「已复制」）。

### 新建作品弹窗

`<Dialog>`，标题「新作品」：`Field` 标题（`Input id="new-work-title"`）、`Field` 账号（`Select`，默认「一叶之桐 · 知乎」）、`Field` 栏目（`Select`，跟着账号变，默认第一个）；底部「取消」「加上」（标题为空时禁用，`data-new-work-submit`）。提交后往 `rows` 最前面加一个作品：编号 `new-1`、`new-2`……，状态 idea，`createdAt` / `updatedAt` 为 `TODAY`，没有版本，`origin: "idea"`；`toast.success("加到灵感列了")`。

**数据**：`WORK_ROWS`、`workRow`、`toolName`、`metricText`（`@/lib/metrics`）；`ACCOUNTS`、`PLATFORMS`、`columnOf`（`@/data/accounts`）；`RUNS`（`@/data/tools`）；`pubDaily`（`@/data/series`）；`WORK_STATUS_LABEL`、`WORK_STATUS_ORDER`、`PUB_FORMAT_LABEL`、`RUN_STATE_LABEL`（`@/data/labels`）；`copyText`（`@/lib/platform`）。

**状态**：
- 筛选后一个都没有：看板和列表位置都换成 `<EmptyState icon={FileText} title="没有符合条件的作品" action={<Button variant="outline" size="sm" onClick={重置}>清除筛选</Button>} />`
- `open` 参数指向不存在的作品：不打开抽屉
- 长标题：卡片 `line-clamp-2`，表格 `truncate`，抽屉里完整换行

**响应式**：看板 `md` 两列、`xl` 四列、手机一列；筛选栏在 `FilterBar` 里横向滚动；表格横向滚动；抽屉手机全宽。

**文案**：「作品」「看板」「列表」「新作品」「搜标题」「全部账号」「全部平台」「全部状态」「只看待发」「清除筛选」「更早的 N 篇」「没有作品」「还没有版本」「各平台版本」「近 14 天阅读」「来源」「备注」「回填链接」「登记」「打开链接」「复制链接」「复制标题」，其余来自数据。
