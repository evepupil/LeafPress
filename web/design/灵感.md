# 灵感 `/ideas/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label`、按钮文字的地方，交互检查会用到，**名字和取值不能改**。

本页节奏：视图栏 → 速记框（白卡）→ 灵感看板（`bg-column` 列里放白卡）→ 下面左右两张白卡：开发记录里的素材、收藏与对标。
本页核心动作：在顶部速记框记一条灵感。
本页最重要的区块：I2 灵感看板，允许写得最长。

灵感列表放在共享状态 `useIdeas`（`@/state/ideas`）里，速记框、看板、素材「收进灵感」、总览页的速记、侧栏的计数共用它。

## I1 速记框 `src/features/ideas/capture.tsx`（`"use client"`）

**外层**：`<section id="capture" aria-label="记灵感" className="rounded-lg border border-line bg-card px-3 py-2.5 shadow-sm">`。

**元素**：
1. 表单 `<form className="flex flex-wrap items-center gap-1.5 md:flex-nowrap" onSubmit={…}>`：
   - `<Lightbulb className="hidden size-4 shrink-0 text-fg-2 md:block" aria-hidden />`
   - `<Input id="idea-capture-input" data-idea-input aria-label="灵感" placeholder="记一条灵感，回车记下" value={text} onChange={…} className="h-7 w-full md:flex-1" />`
   - 账号 `Select`（触发器 `h-7 w-auto min-w-28 text-xs`，`data-idea-account`）：「不挂账号」+ 5 个账号（选项显示 `PlatformMark` + 名字 +「· 平台名」），默认「不挂账号」
   - 栏目 `Select`（`data-idea-column`）：选了账号才可用（否则 `disabled`，显示「栏目」），选项是该账号的栏目，切换账号时重置为第一个栏目
   - `<Button type="submit" size="sm" data-idea-submit disabled={!text.trim()}>记下</Button>`
2. 来源计数 `<div className="mt-2 flex flex-wrap items-center gap-1.5 text-xs text-fg-2" data-idea-sources>`：按 `IDEA_SOURCE_LABEL` 的顺序，每种来源一个 `<span className="inline-flex items-center gap-1">` + 来源图标（`size-3 text-fg-3`，quick → `PenLine`，devlog → `FolderGit2`，cloudmind → `Sparkles`，bookmark → `Bookmark`，trend → `TrendingUp`）+ `{标签} {个数}`；个数为 0 的不显示

**数据**：`useIdeas().ideas`、`ACCOUNTS`、`IDEA_SOURCE_LABEL`。初始来源计数：随手记 7、开发记录 5、CloudMind 1、收藏 1、热点 2。

**交互**：受控字段 `text`、`accountId`（`""` 表示不挂）、`columnId`。提交：`add({ text: text.trim(), accountId: accountId || undefined, columnId: accountId ? columnId : undefined, source: "quick" })`，`toast.success("记下了")`，清空 `text`（账号、栏目保留）。

**状态**：文字为空时「记下」禁用。

**响应式**：手机上输入框占满一行，两个下拉和按钮换到第二行；`md` 起一行。

**文案**：「记一条灵感，回车记下」「不挂账号」「栏目」「记下」「记下了」。

## I2 灵感看板 `src/features/ideas/board.tsx`（`"use client"`）—— 本页最重要

**外层**：`<section id="board" aria-labelledby="board-title">`（不加底色）。

**元素**：
1. 标题行 `<div className="flex flex-wrap items-center gap-2 pb-1">`：`<h2 id="board-title" className="text-sm font-medium">灵感</h2>` + `<span className="text-sm text-fg-2 tabular" data-idea-count>{当前显示的张数}</span>` + 右边 `ml-auto flex items-center gap-3`：
   - 账号筛选 `Select`（触发器 `h-6 w-auto text-xs`，`data-idea-filter`）：「全部账号」+ 5 个账号
   - 显示搁置：`<Switch id="show-shelved" checked={showShelved} onCheckedChange={…} data-idea-shelved />` + `<Label htmlFor="show-shelved" className="text-xs text-fg-2">显示搁置</Label>`
2. 看板 `<div className={…}>`，类名对象映射：共用 `grid items-start gap-(--gap-card) md:grid-cols-2`；不显示搁置 `xl:grid-cols-4`，显示搁置 `xl:grid-cols-5`。列按 `IDEA_STATUS_ORDER`（收件箱、值得写、已排期、已转作品、搁置；搁置只在开关打开时出现）：
   `<BoardColumn title={IDEA_STATUS_LABEL[s]} count={该列张数} icon={…} className="min-w-0">`，图标：inbox → `<Inbox className="size-4 text-fg-2" aria-hidden />`，promising → `<Star …/>`，scheduled → `<CalendarDays …/>`，converted → `<CheckCheck …/>`，shelved → `<Archive …/>`
3. 灵感卡片（列内按 `createdAt` 倒序）：
   `<div data-idea-card={idea.id} data-status={idea.status} className="flex min-w-0 flex-col gap-1.5 rounded-lg border border-line bg-card px-3 py-2.5 shadow-sm">`
   - 第一行 `flex items-start gap-2`：文字 `<p className="min-w-0 flex-1 text-sm line-clamp-3">{idea.text}</p>` + 操作菜单 `DropdownMenu`：触发器 `<IconButton label="操作" size="icon-xs" data-idea-menu><Ellipsis /></IconButton>`（`asChild` 包在 `DropdownMenuTrigger` 里）；菜单项：「移到收件箱」「移到值得写」「移到已排期」「搁置」（当前状态那一项不出现；已转作品的卡片只有「搁置」）、分隔线、「转成作品」（已转作品的不出现，`data-idea-convert`）
   - 第二行 `flex flex-wrap items-center gap-1 text-xs text-fg-2`：来源 `<LabelChip icon={来源图标} title={idea.sourceDetail}>{IDEA_SOURCE_LABEL[source]}</LabelChip>`；有账号时 `<AccountTag account={…} />`；有栏目时 `<ColorDot />` + 栏目名；右边 `ml-auto` `formatRelative(idea.createdAt)`
   - 已转作品时第三行 `<Link href={`/works/?open=${idea.workId}`} className="truncate text-xs text-fg-2 hover:text-fg">→ {作品短标题}</Link>`（新转的作品在作品表里找不到时，显示「→ 新作品」且不链接）

**数据**：`useIdeas`、`ACCOUNTS`、`columnOf`、`WORKS`（找作品标题）、`IDEA_STATUS_LABEL`、`IDEA_STATUS_ORDER`、`IDEA_SOURCE_LABEL`。初始：收件箱 4、值得写 5、已排期 1、已转作品 4、搁置 2（共 16，默认显示 14）。

**交互**：
- `filterAccount: string`，默认 `"all"`：只显示挂在这个账号上的灵感
- `showShelved: boolean`，默认 `false`
- 菜单「移到…」→ `move(id, status)`，`toast.success(\`已移到「${IDEA_STATUS_LABEL[status]}」\`)`；「搁置」同理
- 「转成作品」→ `convert(id)`，`toast.success("已转成作品")`

**状态**：某列为空时列里放 `<p className="px-2 py-3 text-xs text-fg-2">没有灵感</p>`；筛选后全部为空时看板位置显示 `<EmptyState icon={Lightbulb} title="这个号还没有灵感" />`。

**响应式**：手机一列，`md` 两列，`xl` 四列（显示搁置时五列）。

**文案**：「灵感」「全部账号」「显示搁置」「操作」「移到收件箱」「移到值得写」「移到已排期」「搁置」「转成作品」「没有灵感」「已转成作品」。

## I3 开发记录里的素材 `src/features/ideas/materials.tsx`（`"use client"`）

**外层**：`<section id="materials" aria-labelledby="materials-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`。

**元素**：
1. 标题行 `flex h-10 items-center gap-2 border-b border-line px-3`：`<FolderGit2 className="size-4 text-fg-2" aria-hidden />` + `<h2 id="materials-title" className="text-sm font-medium">开发记录里的素材</h2>` + `<span className="text-sm text-fg-2 tabular">6</span>`（`DEV_MATERIALS.length`）+ 右边 `ml-auto text-xs text-fg-2`：`来自 {项目数} 个项目`（不同 `project` 的个数，当前 2）
2. 列表 `<ul className="divide-y divide-line">`，每项 `<li data-material={m.id} className="flex min-w-0 gap-3 px-3 py-2.5">`：
   - 左列 `min-w-0 flex-1`：
     - 第一行 `flex flex-wrap items-center gap-1.5 text-xs text-fg-2`：`<LabelChip>{MATERIAL_KIND_LABEL[kind]}</LabelChip>` + `{m.project}` + `·` + `formatDay(m.date)`
     - 标题 `mt-1 text-sm font-medium`
     - 摘录 `mt-0.5 line-clamp-2 text-xs text-fg-2`
     - 出处 `mt-0.5 truncate font-mono text-xs text-fg-2`：`m.path`
   - 右列：`<Button variant="outline" size="sm" data-material-collect disabled={已收} onClick={…}>{已收 ? "已收进" : "收进灵感"}</Button>`（`self-start`）

**数据**：`DEV_MATERIALS`（6 条，全部来自 LeafPress 和 DeverDesk 的真实记录）、`MATERIAL_KIND_LABEL`。

**交互**：`collected: Set<string>`。点「收进灵感」→ `add({ text: m.title, source: "devlog", sourceDetail: \`${m.project} · ${MATERIAL_KIND_LABEL[m.kind]}\` })`，把这条加进 `collected`，`toast.success("收进灵感了")`。

**状态**：列表为空时 `<EmptyState icon={FolderGit2} title="最近没有新的开发记录" />`。

**响应式**：按钮始终在右侧，`self-start`；左列文字截断。

**文案**：「开发记录里的素材」「来自 N 个项目」「收进灵感」「已收进」「收进灵感了」。

## I4 收藏与对标 `src/features/ideas/bookmarks.tsx`（服务端组件）

**外层**：`<section id="bookmarks" aria-labelledby="bookmarks-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`。

**元素**：
1. 标题行 `flex h-10 items-center gap-2 border-b border-line px-3`：`<Bookmark className="size-4 text-fg-2" aria-hidden />` + `<h2 id="bookmarks-title" className="text-sm font-medium">收藏与对标</h2>`
2. 小标题 `<h3 className="px-3 pt-2.5 pb-1 text-xs font-medium text-fg-2">收藏</h3>`，下面 `<ul>`，每条 `<li data-bookmark={b.id} className="flex min-w-0 items-start gap-2 px-3 py-1.5">`：平台是 `"web"` → `<Globe className="mt-0.5 size-3.5 shrink-0 text-fg-3" aria-hidden />`，否则 `<PlatformMark platform size={14} className="mt-0.5" />`；`<div className="min-w-0 flex-1">`：`<a href={b.url} target="_blank" rel="noreferrer" className="block truncate text-sm hover:underline">{b.title}</a>` + `<p className="truncate text-xs text-fg-2">{b.note}</p>`；右边 `shrink-0 text-xs text-fg-2 tabular` 的 `formatDayShort(b.savedAt)`
3. 小标题 `<h3 className="border-t border-line px-3 pt-2.5 pb-1 text-xs font-medium text-fg-2">对标账号</h3>`，下面 `<ul>`：把每个账号的 `benchmarks` 展开（带上所属账号），每条 `<li data-benchmark className="flex min-w-0 items-start gap-2 px-3 py-1.5">`：图标规则同上；`<div className="min-w-0 flex-1">`：名字 `truncate text-sm`；说明 `truncate text-xs text-fg-2`；右边 `<AccountTag account={所属账号} className="max-w-28 shrink-0" />`
4. 底部留 `pb-1.5`

**数据**：`BOOKMARKS`（5）、`ACCOUNTS[].benchmarks`（共 7：知乎 3、博客 1、公众号 1、B站 1、小红书 1）。

**交互**：只有站外链接。

**状态**：收藏为空时这一节显示 `<p className="px-3 py-2 text-sm text-fg-2">还没有收藏</p>`；对标为空同理「还没有对标账号」。

**响应式**：一列，文字截断。

**文案**：「收藏与对标」「收藏」「对标账号」。
