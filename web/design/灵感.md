# 灵感 `/ideas/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐。
> 凡是写了 `data-*` 属性、`id`、`aria-label`、按钮文字的地方，交互检查会用到，**名字和取值不能改**。

本页是专门产出灵感的地方：随手记、AI 批量跑、定时「跑灵感」都往收件箱里放；你在这里改细节、挑值得写的，最后「转作品」——选几个平台就生成几个作品，作品出现在作品页「待实现」一列。
本页节奏：上面一行两格（速记框 | 跑灵感）→ 下面三列灵感看板（`bg-column` 列里放白卡）→ 点卡片右侧滑出编辑抽屉。
本页核心动作：在看板上点开一条灵感改细节；把卡片拖到「值得写」；点「转作品」选平台。
本页最重要的区块：I3 灵感看板。

页面文件已写好（见 DESIGN.md 4.1），`meta.tsx` 已写好。L3 写 `capture.tsx`、`harvest.tsx`、`board.tsx`，看板可拆 `board-card.tsx`、`board-column.tsx`、`board-sheet.tsx`、`board-menu.tsx`。旧版本的写法可以参考：`git show HEAD:web/src/features/ideas/board-card.tsx`、`git show HEAD:web/src/features/ideas/capture.tsx`。

## I1 速记 `src/features/ideas/capture.tsx`（`"use client"`）

**外层**：`<section id="capture" aria-labelledby="capture-title" className="rounded-lg border border-line bg-card shadow-sm">`。
- 标题行 `flex h-10 items-center gap-2 border-b border-line px-3`：`SquarePen`（`size-4 text-fg-2`）+ `<h2 id="capture-title" className="text-sm font-medium">记灵感</h2>`。
- 表单 `p-3 flex flex-col gap-2`：
  1. `<Textarea id="idea-capture-text" aria-label="灵感" rows={2} placeholder="一句话就行" />`，⌘/Ctrl + 回车提交。
  2. 一行 `flex items-center gap-2`：账号 `Select`（`id="idea-capture-account"`，触发器 `h-7 w-auto min-w-[160px] text-xs`；选项「不挂账号」+ 4 个账号，用 `<AccountTag account size="md" showPlatform />`，默认「不挂账号」）+ 右侧 `ml-auto` 的 `<Button size="sm" data-idea-capture-submit disabled={!text.trim()}>记下</Button>`。
- 提交：`useIdeas.getState().add({ text, accountId, source: "quick" })`，清空文字（账号保留），`toast.success("记下了")`。新卡片出现在收件箱最上面。

## I2 跑灵感 `src/features/ideas/harvest.tsx`（`"use client"`）

定时工作流「跑灵感」的状态，和现在跑一次的按钮。

**外层**：`<section id="harvest" aria-labelledby="harvest-title" className="rounded-lg border border-line bg-card shadow-sm">`。
- 标题行（同 I1）：`Sparkles` + `<h2 id="harvest-title">跑灵感</h2>` + `<span className="text-xs text-fg-2">每天 08:00</span>`（取 `SCHEDULED` 里 `idea-harvest` 的 `schedule`）+ 右侧 `ml-auto` `<Button size="sm" variant="outline" data-harvest-run>`（`RefreshCw`）「现在跑一次」。
- 内容 `p-3 flex flex-col gap-2`：
  1. 最近一次：一行 `flex items-center gap-2 text-sm`：`RunResultIcon result={lastResult}` + `formatRelative(lastRunAt)` + `·` + `lastNote`（例：「新增 3 条灵感」，`data-harvest-note`）。数据取 `useSchedules((s) => s.runs["idea-harvest"])`。
  2. 扫哪些地方：`flex flex-wrap gap-1`，`SCHEDULED` 里它的 `steps` 前三个（扫开发记录、读 CloudMind 记忆、看热点）各一个 `LabelChip`。
  3. 来源分布：一行 `text-xs text-fg-2`，按 `IDEA_SOURCE_LABEL` 统计**当前全部灵感**的来源条数，只列有的，用「 · 」连：例「随手记 6 · 开发记录 5 · CloudMind 1 · 热点 1 · 收藏 1 · AI 批量 1 · 定时跑 2」（`data-source-mix`）。
- 点「现在跑一次」：按钮变禁用 + `Spinner` 约 0.8 秒（`setTimeout`，组件卸载时清掉），然后 `const note = runSchedule("idea-harvest")`，`toast(note)`。第一次、第二次各放 2 条和 1 条新灵感进收件箱（来源「定时跑」），第三次起「没有新的灵感」。

## I3 灵感看板 `src/features/ideas/board.tsx`（`"use client"`）—— 本页最重要

**外层**：`<section id="board" aria-label="灵感看板">`，里面 `grid items-start gap-(--gap-card) md:grid-cols-3`（手机一列一列往下排）。

### 状态

```ts
openId: string | null              // 编辑抽屉打开的灵感，和地址栏 open 参数同步（读：useSearchParams；写：router.replace("/ideas/?open=…" 或 "/ideas/", { scroll: false })）
convertSource: ConvertSource | null
deleting: Idea | null
```

数据：`const ideas = useIdeas((s) => s.ideas)`、`const works = useWorks((s) => s.works)`；每列 `useMemo(() => sortIdeas(ideas, status), …)`。

### 三列（`BoardColumn`，顺序 `IDEA_STATUS_ORDER`）

| 列 | `icon` | `title` | 拖进来 |
|---|---|---|---|
| inbox | `Inbox`（`size-4 text-fg-2`） | 收件箱 | `drop(id, "inbox", beforeId)` |
| promising | `Star`（`size-4 text-fg-2`） | 值得写 | `drop(id, "promising", beforeId)` |
| converted | `ArrowRight`（`size-4 text-fg-2`） | 已转作品 | **不改状态**，打开转作品弹窗：`setConvertSource({ kind: "idea", idea })` |

列外层 `<div {...dropProps} data-idea-column={status}>`；`count` = 条数；拖到上方时加虚线框，`over` 时在 `beforeId` 前面画 `DropLine`（已转作品一列不画线，只加虚线框）。空列：「这一列是空的」（`px-2 pb-2 text-sm text-fg-2`）。
已转作品一列默认显示前 8 张 +「再显示 8 个」按钮（`data-show-more`）。

### 卡片 `board-card.tsx`

外层 `<div data-drag-id={idea.id} data-idea-card={idea.id} draggable={idea.status !== "converted"} …>`，样式同作品卡片（`group flex flex-col gap-1.5 rounded-lg border border-line bg-card px-3 py-2.5 shadow-sm hover:border-line-3 cursor-pointer`），拖动中 `opacity-50`；整卡点击打开抽屉。

- 第一行（`flex h-[18px] items-center gap-2 text-xs text-fg-2`）：来源 `IDEA_SOURCE_LABEL[source]` + （有 `sourceDetail` 时）`· {sourceDetail}`（`truncate`）+ 右侧 `ml-auto`：卡片菜单按钮（悬停出现，规则同作品卡片）+ `formatRelative(createdAt)`。
- 第二行：一句话 `<button className="line-clamp-3 text-left text-sm">`（`stopPropagation` 后打开抽屉，`focusRing`）。
- 第三行（有 `detail` 时）：`<p className="line-clamp-2 text-xs text-fg-2">{detail}</p>`。
- 第四行 `flex flex-wrap items-center gap-1`：
  - 挂了账号：`<AccountTag account={…} />`
  - 已转作品：每个 `workIds` 里还存在的作品一个 `<WorkChip work={…} />`（作品被删了就跳过）
  - 没转过的：右侧 `ml-auto` 一个 `<Button size="xs" variant="outline" data-idea-convert>`（`ArrowRight`）「转作品」，悬停才出现（同菜单按钮的透明度写法，手机常显）；点了打开转作品弹窗。已转作品的卡片也能再转（菜单里有），用于再发一个平台。

### 卡片菜单（`DropdownMenu`，触发器 `IconButton size="icon-xs" label="更多"`，`Ellipsis`，`data-card-menu`）

「转作品」(`ArrowRight`) · 「挪到值得写」(`Star`，只在收件箱) / 「挪回收件箱」(`Inbox`，只在值得写) · 分隔线 · 「删除」(`Trash2`，destructive)。挪列用 `drop(id, status, null)`。删除走 `ConfirmDialog`（`title={\`删除这条灵感？\`}`、`description` 为灵感一句话、`confirmLabel="删除"`、destructive），确认后 `remove(id)`、`toast("已删除")`；已转出去的作品不受影响。

### 编辑抽屉 `board-sheet.tsx`

`Sheet` 右侧，`data-[side=right]:sm:max-w-[480px]`，`onInteractOutside={ignoreToastInteraction}`。打开的是 `openId` 对应的灵感；找不到就不渲染。

- 头：`SheetTitle` 写「灵感」+ 状态 `LabelChip`（`IDEA_STATUS_LABEL`）；`SheetDescription` `sr-only`「编辑灵感」。
- 主体 `flex flex-col gap-3 px-4 py-3`（草稿组件 `key={idea.id}`，失焦保存）：
  1. `<Label htmlFor="idea-text">一句话</Label>` + `<Textarea id="idea-text" rows={2} />` → `update(id, { text })`（清空则还原）
  2. `<Label htmlFor="idea-detail">细节</Label>` + `<Textarea id="idea-detail" rows={5} placeholder="想写什么、素材在哪" />` → `update(id, { detail })`
  3. 账号 `Select`（`id="idea-account"`，「不挂账号」+ 4 个），改了立刻 `update(id, { accountId })`
  4. 来源一行（只读，`text-xs text-fg-2`）：`IDEA_SOURCE_LABEL` + `sourceDetail` + ` · ` + `formatRelative(createdAt)`
  5. 已转作品时：小标题「转出去的作品」+ 每个作品一行（`flex items-center gap-2 h-8`）：`WorkStatusIcon` + 作品标题（`truncate`，`Link` 到 `/?open=<编号>`）+ 右侧 `PlatformMark` + 状态文字（`text-xs text-fg-2`）。
- 底部 `border-t border-line px-4 py-3 flex gap-2`：`<Button size="sm" data-sheet-convert>`（`ArrowRight`）「转作品」+ 右侧 `ml-auto` `IconButton label="删除"`（`Trash2`）。

### 转作品

`<ConvertDialog source={convertSource} onClose={() => setConvertSource(null)} />`。转完灵感自动挪到「已转作品」最上面（`convertToWorks` 已处理），卡片上出现 `WorkChip`。

### 状态与响应式

- 手机：三列上下排；卡片菜单常显；拖动不可用，靠菜单挪列。
- 长文字：一句话三行截断、细节两行截断，抽屉里看全文。
