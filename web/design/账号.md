# 账号 `/accounts/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label`、按钮文字的地方，交互检查会用到，**名字和取值不能改**。

## 第三版改动（最新，以这里为准；和下面第二版、第一版冲突时按这里）

1. **栏目和目标整套去掉**：卡片上的栏目标签、「本周发布 0/2」里的目标都不要了，本周发布只写发了几篇。A2 方向对照表、A3 筹备中整块删掉。
2. **卡片的一句话简介**取账号档案（Markdown）的第一段（`markdownSummary(useProfile(id))`），档案改了这里跟着变。
3. **卡片加接入状态**：阶段标签后面一个 `LabelChip`（外面包 `data-setup-state`）：接好了（绿）/ 有问题（红）/ 没接完（黄），悬停显示还缺什么。数据还没接的号，粉丝、近 7 天浏览显示「—」，不画小柱状图。
4. **新增 A2 接入情况** `src/features/accounts/setup-table.tsx`（`SetupTable`，锚点 `setup`）：一行一个号（`data-setup-row`），五列：账号（下面写接入状态）、作品产出（这个平台的工作流和可用 / 需配置）、数据获取（方式 · 来源 + 状态）、能拿到（粉丝叫法 + 平台的数据项）、还缺什么（`setupView().gaps`，一行一句）。
5. 「加账号」先保留原样，等真接平台时再补齐要填的东西。

## 第二版改动（以这里为准，和下文冲突时按这里）

1. **公众号「ACG萌图宅」整条去掉**：账号只有 4 个（知乎、博客、B站、小红书）。下文所有提到公众号、`wechat-acg`、「72 天没更新」、5 个账号、5 个平台的地方，一律按 4 个算。加账号弹窗的平台选项是 4 个（博客、知乎、B站、小红书），默认知乎。
2. **不再有「版本」**：一个作品只对应一个平台。A2「近 30 天」改用 `publishedWorks(accountId)`（`@/lib/metrics`）里 `publishedAt` 在 `addDays(LATEST_DAY, -29)` 到 `LATEST_DAY` 之间的个数：知乎 7、博客 11、B站 0、小红书 0。`PUBLICATIONS` 已删除。
3. **A1 账号卡片加一行「手上的活」**（放在卡片里粉丝那一行下面、方向说明上面）：`<Link href={`/?platform=${platform}`} data-account-tasks className="flex items-center gap-2 text-xs text-fg-2 hover:text-fg">`，内容是 `WorkStatusIcon` + 状态名 + 数字，三组用 ` · ` 隔开：待实现 N · 进行中 N · 等你处理 N（等你处理大于 0 时那一组用 `text-warn`）。数字来自 `useWorks((s) => s.works)` 按 `accountId` 和状态数（用 `useMemo`）。初始：知乎 5 · 1 · 2；博客 1 · 0 · 0；B站 0 · 0 · 1；小红书 0 · 0 · 1。三组都是 0 时写「手上没有活」。
4. 卡片「看作品」之类指向 `/works/` 的链接，一律改成 `/?platform=<平台>`。

本页节奏：视图栏 → 账号卡片网格（白卡）→ 方向对照表（白卡表格，占满一行）→ 筹备中（`bg-column` 看板列，占满一行，里面的卡片 `md` 起两列并排）。
本页核心动作：点账号卡片进详情。
本页最重要的区块：A1 账号卡片，允许写得最长。

## A1 账号卡片 `src/features/accounts/accounts-grid.tsx`（`"use client"`）—— 本页最重要

**外层**：`<section id="accounts" aria-labelledby="accounts-title">`（不加底色，卡片自己是白卡）。

**元素**：
1. 标题行 `<div className="flex h-8 items-center gap-2 pb-1">`：`<h2 id="accounts-title" className="text-sm font-medium">全部账号</h2>` + `<span className="text-sm text-fg-2 tabular" data-accounts-count>{卡片数}</span>` + 右边 `ml-auto` 的 `<Button variant="outline" size="sm" onClick={打开弹窗} data-add-account><Plus />加账号</Button>`
2. 网格 `<div className="grid gap-(--gap-card) sm:grid-cols-2 xl:grid-cols-3">`，每个账号一张卡（顺序同 `ACCOUNT_SUMMARIES`）：
   `<Link href={`/accounts/${a.id}/`} data-account-card={a.id} className={cn("flex min-w-0 flex-col gap-2.5 rounded-lg border border-line bg-card px-4 py-3 shadow-sm transition-[border-color] duration-(--dur-fast) hover:border-line-3", focusRing)}>`
   - 第一行 `flex min-w-0 items-center gap-2.5`：`<PlatformMark platform={a.platform} size={28} />` + `<div className="min-w-0">`（名字 `truncate text-sm font-medium`；第二行 `truncate text-xs text-fg-2`：`{平台名} · {a.handle}`）+ 右边 `ml-auto flex shrink-0 gap-1`：阶段标签 `<LabelChip color={…}>{STAGE_LABEL[stage]}</LabelChip>`（颜色对象映射：active → `"green"`，preparing → `"amber"`，paused → `"gray"`）；`stale` 时再加 `<LabelChip color="red">{daysSincePublish} 天没更新</LabelChip>`
   - 定位 `<p className="line-clamp-2 text-sm text-fg-2">{a.positioning}</p>`
   - 三格数据 `<div className="grid grid-cols-3 gap-2 border-t border-line pt-2.5">`，每格 `<div className="flex min-w-0 flex-col gap-0.5">` + 标签 `text-xs text-fg-2` + 值：
     - 标签 `a.audienceLabel`；值 `<span className="flex items-baseline gap-1"><span className="text-sm font-medium tabular" data-account-followers>{formatCount(followers)}</span><Delta value={followers7d} kind="count" /></span>`
     - 标签「本周发布」；值 `text-sm font-medium tabular`：`{postsThisWeek}/{postsTarget}`
     - 标签 `近 7 天${a.readsLabel}`；值 `<span className="flex items-baseline gap-1"><span className="text-sm font-medium tabular">{formatCount(reads7d)}</span><Delta value={readsChange} /></span>`
   - 栏目 `<div className="flex flex-wrap gap-1">`：每个栏目 `<LabelChip color={column.color}>{column.name}</LabelChip>`
   - 底行 `flex min-w-0 items-center gap-2`：`<SourceBadge source={a.dataSource} />` + `<MiniBars values={weeklyGain} className="ml-auto" />`
3. 新加的账号（弹窗提交后追加在网格最后）：不是链接，是 `<div data-account-card={`new-${n}`} className="flex min-w-0 flex-col gap-2.5 rounded-lg border border-dashed border-line-3 bg-card px-4 py-3">`，内容只有第一行（平台标识、名字、「{平台名} · 待定」、`<LabelChip color="amber">筹备中</LabelChip>`）、定位（没填就不显示）和 `<SourceBadge source={{ mode: "manual", provider: "", schedule: "", lastResult: "never" }} />`。

**加账号弹窗**：`<Dialog>`，`<DialogTitle>加账号</DialogTitle>`；表单三项：`Field` 平台（`Select id="new-account-platform"`，选项 5 个平台，默认知乎）、`Field` 名字（`Input id="new-account-name" data-new-account-name`）、`Field` 定位（`Textarea id="new-account-positioning" rows={2}`，占位「一句话：写什么、写给谁」）；底部 `<Button variant="outline">取消</Button>` 和 `<Button data-new-account-submit disabled={!name.trim()}>加上</Button>`。提交后关闭弹窗、追加卡片、`toast.success("加好了")`、清空表单。

**数据**：`ACCOUNT_SUMMARIES`（`@/lib/metrics`）、`PLATFORMS`（`@/data/accounts`）、`STAGE_LABEL`（`@/data/labels`）。期望：知乎 5,510（+109）、近 7 天阅读 7,478；公众号 3,257（−7），72 天没更新；B站 41；小红书 7。

**交互**：状态 `added: { platform: PlatformId; name: string; positioning: string }[]`，默认空；弹窗开关 `open: boolean`；表单三个受控字段。

**状态**：粉丝 0 显示 0；`readsChange` 为 null 时 `Delta` 显示「—」；定位过长 `line-clamp-2`。

**响应式**：手机一列，`sm` 两列，`xl` 三列；左右等高（网格默认拉伸），卡片里的元素顶部对齐。

**文案**：「全部账号」「加账号」「本周发布」「近 7 天阅读 / 访问 / 播放 / 浏览」「加上」「取消」「加好了」「一句话：写什么、写给谁」。

## A2 方向对照 `src/features/accounts/direction-matrix.tsx`（服务端组件）

**外层**：`<section id="directions" aria-labelledby="directions-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`。

**元素**：
1. 标题行 `flex h-10 items-center gap-2 border-b border-line px-3`：`<Target className="size-4 text-fg-2" aria-hidden />` + `<h2 id="directions-title" className="text-sm font-medium">方向对照</h2>`
2. 表格外包 `<div className="overflow-x-auto">`，`<table className="w-full min-w-[900px] text-sm">`，表头 `bg-raised text-xs text-fg-2`，`th` 为 `h-8 px-3 text-left font-normal`：
   - 「账号」：`<Link href={`/accounts/${a.id}/`} className={focusRing}><AccountTag account={a} size="md" showPlatform /></Link>`
   - 「定位」：`<span className="block max-w-[260px] truncate text-fg-2" title={a.positioning}>{a.positioning}</span>`
   - 「写给谁」：前两项用「、」连起来，多出来的加 ` +N`，`text-xs text-fg-2`
   - 「栏目」：`<span className="flex items-center gap-1">` + 每个栏目一个 `<ColorDot color={column.color} />` + 栏目数 `text-xs text-fg-2 tabular`
   - 「每周目标」：`{postsPerWeek} 篇`，`tabular`
   - 「近 30 天」：近 30 天（`addDays(LATEST_DAY, -29)` 到 `LATEST_DAY`）在这个号上已发的版本数，`tabular`，单元格加 `data-direction-recent`
   - 「粉丝目标」：`<span className="flex items-center gap-1.5">` + `<ProgressMeter value={goalProgress} />` + `{formatPercent(goalProgress)}`（`text-xs tabular`）+ `<span className="text-xs text-fg-2">/ {formatCount(goals.followers)}</span>`
   - 每行 `<tr data-direction-row={a.id} className="h-10 border-t border-line">`

**数据**：`ACCOUNTS`、`summaryOf`、`PUBLICATIONS`（近 30 天：知乎 7、博客 11、公众号 0、B站 0、小红书 0）、`formatPercent`。

**交互**：只有账号链接。

**状态**：近 30 天为 0 显示 `0`，文字用 `text-fg-2`。

**响应式**：桌面上表格占满一行，账号列不截断，「定位」分到最多的宽度；手机上表格横向滚动。

**文案**：「方向对照」「账号」「定位」「写给谁」「栏目」「每周目标」「近 30 天」「粉丝目标」「篇」。

## A3 筹备中 `src/features/accounts/prep-board.tsx`（`"use client"`）

**外层**：`<div id="prep" className="min-w-0">` 里放 `<BoardColumn icon={<ListChecks className="size-4 text-fg-2" aria-hidden />} title="筹备中" count={2} bodyClassName="grid items-start gap-(--gap-card) md:grid-cols-2">`（个数为筹备中的账号数；卡片 `md` 起两列）。

**元素**：每个筹备中的账号一张白卡 `<Surface className="flex flex-col gap-2 px-3 py-2.5" data-prep-account={a.id}>`：
1. 第一行 `flex min-w-0 items-center gap-2`：`<AccountTag account={a} size="md" showPlatform />` + 右边 `ml-auto text-xs text-fg-2 tabular` 的 `开号 {formatDay(a.since)}`
2. 进度行 `flex items-center gap-2 text-xs text-fg-2 tabular`：`<span data-prep-progress={a.id}>{已完成}/{总数}</span>` + `<ProgressMeter value={已完成 / 总数} className="w-16" />`
3. 清单 `<ul className="flex flex-col">`，每项
   `<li><button type="button" role="checkbox" aria-checked={done} data-prep-item onClick={切换} className={cn("flex min-h-8 w-full items-center gap-2 rounded-md px-1.5 text-left text-sm hover:bg-hover", focusRingInset)}>`
   + 完成 `<StatusIcon glyph="check" tone="done" />` / 未完成 `<StatusIcon glyph="ring" tone="idle" />` + 文字（完成的用 `text-fg-2`）

**数据**：`ACCOUNTS` 里 `stage === "preparing"` 的号（B站 3/5、小红书 1/3），清单来自 `a.prep`。

**交互**：状态 `checked: Record<string, boolean[]>`，初始来自数据；点一项切换完成，进度跟着变。

**状态**：没有筹备中的号时，列里放 `<p className="px-2 py-3 text-xs text-fg-2">没有筹备中的号</p>`。

**响应式**：一列。

**文案**：「筹备中」「开号」。
