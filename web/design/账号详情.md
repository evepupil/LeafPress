1. **D2 换成账号档案** `src/features/account-detail/profile.tsx`（`AccountProfile`，锚点 `profile`）：一份随便写的 Markdown（定位、写给谁、文风、禁用词、对标、目标、调整记录都写在里面）。标题行写「档案」和文件位置 `~/.leafpress/accounts/<编号>.md`，右边「复制档案」和「编辑」（`data-profile-edit`）；平时用共享的 `Markdown` 组件排好版显示（`data-profile`），编辑时一个大输入框（`#profile-input`、`data-profile-input`，等宽小字），「保存」（`data-profile-save`，⌘/Ctrl + 回车也行）。存在 `useAccounts.profiles`。D1 账号头的锚点改成 `overview`。

3. **D5 换成接入** `src/features/account-detail/setup.tsx`（`AccountSetup`，锚点 `setup`，`data-setup-block`）：标题行右边接入状态（`data-setup-state`）。三段：

   - 数据获取（`data-setup-source={status}`）：方式 · 来源 · 什么时候拉、状态；拉取失败写原因和怎么修；还没接写「打算：…」；「能拿到：粉丝叫法、平台数据项」；没接的以外有「现在拉一次」（`data-setup-pull`，只拉这个号）；

## D2 方向档案 `src/features/account-detail/direction.tsx`（`"use client"`）—— 本页最重要

**外层**：`<section id="direction" aria-labelledby="direction-title" className="rounded-lg border border-line bg-card px-4 py-3 shadow-sm">`。

**状态**：

```ts
editing: boolean            // 默认 false
draft: { positioning: string; audience: string; styleRules: string; bannedPhrases: string }   // 进入编辑时从当前值生成
current: { positioning: string; audience: string[]; styleRules: string[]; bannedPhrases: string[]; log: { date: DayKey; note: string }[] }   // 初始来自账号数据
```

**元素**：
1. 标题行 `flex items-center gap-2 pb-2`：`<Target className="size-4 text-fg-2" aria-hidden />` + `<h2 id="direction-title" className="text-sm font-medium">方向</h2>` + 右边 `ml-auto flex gap-1.5`：
   - 查看时：`<Button variant="ghost" size="sm" onClick={开始编辑} data-direction-edit-start><Pencil />编辑</Button>`
   - 编辑时：`<Button variant="outline" size="sm" onClick={取消}>取消</Button>` + `<Button size="sm" onClick={保存} data-direction-save>保存</Button>`
2. 内容网格 `<div className="grid gap-x-6 gap-y-4 md:grid-cols-2">`，每一节 `<div className="flex min-w-0 flex-col gap-1.5">` + 节标题 `<h3 className="text-xs font-medium text-fg-2">`：
   - **定位**（`md:col-span-2`）：查看 `<p className="text-sm" data-direction-positioning>{current.positioning}</p>`；编辑 `<Textarea data-direction-input="positioning" aria-label="定位" rows={2} value={draft.positioning} …/>`
   - **写给谁**：查看 `flex flex-wrap gap-1`，每项 `<LabelChip>{item}</LabelChip>`；编辑 `<Input data-direction-input="audience" aria-label="写给谁" …/>`，值是用「、」连起来的文字，保存时按「、」或「,」拆开、去空白、去空项
   - **禁用句式**：查看同上（`LabelChip`），为空时 `<span className="text-sm text-fg-2">没有设置</span>`；编辑 `<Input data-direction-input="bannedPhrases" aria-label="禁用句式" …/>`，同样按「、」拆
   - **栏目**（`md:col-span-2`）：只读（编辑时也照常显示）。`<ul className="flex flex-col gap-1">`，每个栏目
     `<li data-direction-column={column.id} className="flex min-w-0 items-center gap-2 text-sm">`：`<ColorDot color={column.color} />` + `<span className="min-w-0 flex-1 truncate">{column.name}</span>` + `<span className="text-xs text-fg-2 tabular">计划 {formatPercent(targetShare)} · 实际 {formatPercent(share)}</span>` + `<ProgressMeter value={share} className="w-16" />`；`pubs === 0` 的栏目在后面加 `<span className="text-xs text-warn">近 12 周没发过</span>`
     数据来自 `columnRows(accountId)`
   - **文风规矩**（`md:col-span-2`）：查看 `<ol className="flex list-decimal flex-col gap-1 pl-5 text-sm marker:text-fg-2">`；编辑 `<Textarea data-direction-input="styleRules" aria-label="文风规矩" rows={5} …/>`，一行一条，保存时按换行拆
   - **对标**：`<ul className="flex flex-col gap-1.5">`，每项 `flex min-w-0 items-start gap-2`：平台是 `"web"` 时 `<Globe className="mt-0.5 size-3.5 shrink-0 text-fg-3" aria-hidden />`，否则 `<PlatformMark platform size={14} className="mt-0.5" />` + `<div className="min-w-0">`（名字 `text-sm`；说明 `text-xs text-fg-2`）；为空时「没有对标账号」`text-sm text-fg-2`
   - **调整记录**：`<ul className="flex flex-col gap-1.5" data-direction-log>`，每项 `flex gap-2 text-sm`：日期 `w-16 shrink-0 text-xs text-fg-2 tabular`（`formatDayShort`）+ 内容

**数据**：`accountById(accountId)` 的 `positioning`、`audience`、`styleRules`、`bannedPhrases`、`benchmarks`、`directionLog`；`columnRows(accountId)`。知乎期望：栏目四个，AI 工程化「计划 40% · 实际 50%」、计算机「计划 25% · 实际 50%」、经济管理和认知科学与心理学「近 12 周没发过」；文风规矩 6 条；禁用句式 8 个；对标 3 个；调整记录 2 条。

**交互**：
- 「编辑」：`editing = true`，`draft` 由 `current` 生成（数组用「、」或换行连起来）

**响应式**：手机一列，`md` 起两列（定位、栏目、文风规矩占两列）。

**文案**：「方向」「编辑」「取消」「保存」「定位」「写给谁」「禁用句式」「栏目」「文风规矩」「对标」「调整记录」「计划」「实际」「近 12 周没发过」「没有设置」「没有对标账号」「方向已更新」「修改了方向档案」。
