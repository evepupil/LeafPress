# 工作流 `/workflows/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐。
> 凡是写了 `data-*` 属性、`id`、`aria-label`、按钮文字的地方，交互检查会用到，**名字和取值不能改**。

本页回答三个问题：有哪些发布工作流、每一步谁来做（AI / 自动 / 你来）；创建作品时怎么自动配；定时工作流跑得怎样。工具只是附带列一下。
本页节奏：工作流卡片墙（白卡，`md:grid-cols-2 2xl:grid-cols-3`）→ 一行两格（定时工作流 | 自动配规则）→ 工具表。
本页核心动作：看一个工作流的步骤，找到「你来」的那几步；复制「在 agent 里怎么说」。
本页最重要的区块：F1 发布工作流。

L4 写 `cards.tsx`（可拆 `cards-*.tsx`）、`scheduled.tsx`、`pick-rules.tsx`、`tools.tsx`。页面文件已写好。

## F1 发布工作流 `src/features/workflows/cards.tsx`（`"use client"`）—— 本页最重要

**外层**：`<section id="workflows" aria-label="发布工作流" className="grid items-start gap-(--gap-card) md:grid-cols-2 2xl:grid-cols-3">`，`WORKFLOWS` 每个一张卡。

**卡片**：`<article id={workflow.id} data-workflow={workflow.id} className="flex min-w-0 flex-col rounded-lg border border-line bg-card shadow-sm scroll-mt-3">`（`id` 让 `/workflows/#blog-to-zhihu` 能跳过来；地址带锚点时那张卡加 `ring-2 ring-(--focus-ring)`，用 `useSyncExternalStore` 读 `window.location.hash`，写法照 `src/features/shell/workbench-sidebar.tsx` 的 `useLocationHash`）。

1. **头**（`flex items-center gap-2 border-b border-line px-3 py-2.5`）：`<PlatformMark platform size={18} />` + `<h2 className="truncate text-sm font-medium">{name}</h2>` + `WorkflowStatusIcon` + 状态文字（`text-xs text-fg-2`；需配置用 `text-warn`）+ 右侧 `ml-auto text-xs text-fg-2 tabular`（`data-workflow-usage`）：`在用 {active} · 完成 {done}`（`workflowUsage(works, id)`，`works` 读 `useWorks`）。
2. **说明**（`px-3 pt-2.5 text-sm text-fg-2`）：`summary`。
3. **两个小标签**（`flex flex-wrap gap-1 px-3 pt-2`）：来源 `LabelChip`：`from` 为 idea →「从灵感」、blog-work →「从博客作品」、any →「什么都行」；发布 `LabelChip`：`autoPublish` →「自动发布」（`color="green"`），否则「最后你来投递」（`color="amber"`）。
4. **步骤**（`<ol data-workflow-steps className="flex flex-col gap-px px-3 py-2.5">`），每步一行 `flex min-h-7 items-center gap-2 text-sm`：
   - 序号 `w-4 shrink-0 text-right text-xs text-fg-2 tabular`
   - 种类图形：ai → `Bot`、code → `Terminal`、manual → `Hand`（`size-3.5 shrink-0`；manual 用 `text-warn`，其余 `text-fg-3`）
   - 步骤名（`truncate`；manual 的用 `text-warn`）
   - 右侧 `ml-auto truncate text-xs text-fg-2`：`tool`（没有就空）
   - `data-step-kind={kind}`
5. **需配置提示**（`status === "needs-setup"` 时）：`mx-3 mb-2.5 flex items-start gap-1.5 rounded-md bg-raised px-2.5 py-2 text-xs text-warn` + `TriangleAlert` 图标 + `setupHint`。
6. **脚**（`mt-auto flex items-center gap-2 border-t border-line px-3 py-2`）：`MessageSquare`（`size-3.5 text-fg-3`）+ `<span className="min-w-0 flex-1 truncate text-xs text-fg-2">在 agent 里说「{say}」</span>` + `IconButton size="icon-xs" label="复制说法"`（`Copy`，`copyText(say)` → `toast.success("已复制")`）。

## F2 定时工作流 `src/features/workflows/scheduled.tsx`（`"use client"`）

**外层**：`<section id="scheduled" aria-labelledby="scheduled-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`。
- 标题行 `flex h-10 items-center gap-2 border-b border-line px-3`：`Clock` + `<h2 id="scheduled-title" className="text-sm font-medium">定时工作流</h2>` + 个数。
- `SCHEDULED` 每个一块（`<div data-scheduled={id} className="flex flex-col gap-1.5 px-3 py-2.5">`，块之间 `border-t border-line`）：
  1. 第一行：`RunResultIcon result={run.lastResult}` + 名字（`text-sm font-medium`）+ `<span className="text-xs text-fg-2">{schedule}</span>` + 右侧 `ml-auto` `<Button size="xs" variant="outline" data-run-now>`（`RefreshCw`）「现在跑一次」。
  2. 第二行 `text-xs`：`formatRelative(run.lastRunAt)` + ` · ` + `lastNote`；失败时 `lastNote` 用 `text-bad`，后面跟一个链接「去修复」→ `/data/#sources`（只有 `data-pull`）。
  3. 第三行：`steps` 每个一个 `LabelChip`（`flex flex-wrap gap-1`）。
  `run` 取 `useSchedules((s) => s.runs[id])`。
- 点「现在跑一次」：这一块的按钮禁用 + `Spinner` 约 0.8 秒，然后 `toast(runSchedule(id))`。

## F3 自动配规则 `src/features/workflows/pick-rules.tsx`（服务端组件即可）

创建作品时按什么挑工作流。和 `pickWorkflow` 的规则一致，写死成 5 行：

**外层**：`<section id="rules" aria-labelledby="rules-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`；标题行同 F2（`Workflow` 图标，标题「自动配规则」）。
表格（`w-full text-sm`，表头 `bg-raised h-8 text-xs text-fg-2 font-normal`，行 `h-9 border-t border-line`）三列：平台、来源、工作流。

| 平台 | 来源 | 工作流 |
|---|---|---|
| 博客 | 都行 | 博客写稿 |
| 知乎 | 博客作品 | 博客转知乎 |
| 知乎 | 灵感、直接新建 | 知乎写作 |
| 小红书 | 都行 | 转小红书卡片 |
| B站 | 都行 | 录屏成片 |

平台列用 `PlatformMark` + 平台名；工作流列是链接 `#<工作流编号>`（`text-fg hover:underline`），`data-rule-workflow`。表格下面一行 `px-3 py-2 text-xs text-fg-2`：「作品里可以换成同平台的其他工作流，开始做之前都能换。」

## F4 工具 `src/features/workflows/tools.tsx`（服务端组件即可）

**外层**：同 F2 的卡片外层，`id="tools"`；标题行 `Settings` +「工具」+ 个数（12）。
表格横向可滚（`scroll-thin overflow-x-auto`，`min-w-[640px] table-fixed`），列：名称（`w-[180px]`，`font-medium`）、类型（`w-[72px]`：skill →「skill」、cli →「命令行」、api →「接口」、code →「代码」）、说明（自动宽，`truncate text-fg-2`）、状态（`w-[88px]`：`WorkflowStatusIcon` + 可用 / 需配置）。行 `h-9`，`data-tool-row`。
