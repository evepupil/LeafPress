# 总览 `/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。

**元素**：
1. `left`：`<span className="flex items-center gap-3 text-xs text-fg-2 tabular">`，里面四段，每段一个 `<span data-summary="…">`：
   - `data-summary="inbox"`：`待处理 ` + `<span className="text-fg">12</span>`（数字来自 `INBOX.length`）
   - `data-summary="posts"`：`本周已发 ` + `<span className="text-fg">0/11</span>`（分子是 `ACCOUNT_SUMMARIES` 的 `postsThisWeek` 之和，分母是运营中账号的 `postsTarget` 之和）
   - `data-summary="followers"`，`className="hidden items-center gap-1 sm:inline-flex"`：`粉丝 ` + `<span className="text-fg">9,129</span>` + `<Delta value={122} kind="count" />`（粉丝之和、`followers7d` 之和）
   - `data-summary="reads"`，`className="hidden md:inline"`：`近 7 天阅读 ` + `<span className="text-fg">1.1万</span>`（`reads7d` 之和，`formatCount`）

**数据**：`INBOX`、`ACCOUNT_SUMMARIES`（`@/lib/metrics`），格式化用 `formatCount`。括号里的数字是当前数据下的期望值，不要写死。

**交互**：只有右边的链接。

**状态**：数字为 0 时照常显示 `0`；分母为 0 时显示 `0/0`。

**响应式**：手机只显示前两段，`sm` 起显示粉丝，`md` 起显示阅读。

**文案**：如上。

## H1 待处理 `src/features/home/inbox.tsx`（`"use client"`）—— 本页最重要

**外层**：`<section id="inbox" aria-labelledby="inbox-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`。

**元素**：
1. 标题行 `<div className="flex h-10 items-center gap-2 border-b border-line px-3">`：
   - `<Inbox className="size-4 text-fg-2" aria-hidden />`
   - `<h2 id="inbox-title" className="text-sm font-medium">待处理</h2>`
   - 数量 `<span className="text-sm text-fg-2 tabular" data-inbox-count>`（当前筛选下的条数）
   - 右边 `ml-auto`：`<Segmented label="筛选待处理" value={tone} onChange={setTone} options={[{ value: "all", label: "全部" }, { value: "risk", label: "要紧" }, { value: "progress", label: "进行中" }, { value: "idle", label: "稍后" }]} />`，外面包一层 `<div data-inbox-filter>`
2. 列表 `<ul className="divide-y divide-line">`，每一项：
   `<li data-inbox-item={item.id} data-tone={item.tone} className="flex min-h-12 items-center gap-3 px-3 py-2">`
   - 状态图形：risk → `<StatusIcon glyph="alert" tone="risk" />`；progress 且 kind 为 planned → `<StatusIcon glyph="dot" tone="progress" />`；其余 progress → `<StatusIcon glyph="half" tone="progress" />`；idle → `<StatusIcon glyph="ring" tone="idle" />`
   - 文字列 `<div className="min-w-0 flex-1">`：第一行 `title`（`truncate text-sm text-fg`），第二行 `detail`（`truncate text-xs text-fg-2`）
   - 时间 `<span className="hidden shrink-0 text-xs text-fg-2 tabular sm:block">`：kind 为 planned 时显示 `formatDayRelative(item.at.slice(0, 10))`（「明天」「2 天后」），其余显示 `formatRelative(item.at)`
   - 动作按钮：`<Button variant="outline" size="sm" asChild>`，里面站内用 `<Link href={item.href} data-inbox-action>`，站外（`item.external`）用 `<a href={item.href} target="_blank" rel="noreferrer" data-inbox-action>` 并在文字后加 `<ExternalLink className="size-3" aria-hidden />`；文字是 `item.action`

**数据**：`INBOX`（`@/lib/metrics`），已经按「要紧 → 进行中 → 稍后」排好，直接用。当前数据 12 条：要紧 3（插画出草稿没跑完、技术博客数据拉取失败、ACG萌图宅 72 天没更新）、进行中 7（4 个等你处理的运行 + 3 个排期）、稍后 2（B站、公众号数据没填）。

**交互**：`tone: "all" | InboxTone`，默认 `"all"`；切换后列表只显示该 tone 的项，数量跟着变。

**状态**：
- 全部为空：列表位置显示 `<EmptyState icon={CheckCheck} title="没有待处理的事" />`
- 筛选后为空：`<EmptyState icon={CheckCheck} title="这一类没有待处理的事" />`
- 标题、说明过长：`truncate`，完整文字放在 `li` 的 `title` 属性里

**响应式**：手机隐藏时间列；动作按钮始终可见，不换行（`shrink-0`）。

**文案**：标题「待处理」；筛选「全部 / 要紧 / 进行中 / 稍后」；其余文字来自数据。

**元素**：

   - `<span className="text-xs text-fg-2">{formatWeekRange(THIS_WEEK)}</span>`（「10月5日 – 10月11日」）
   - 右边 `<span className="ml-auto text-xs text-fg-2 tabular" data-cadence-summary>`：`已发 0 · 排期 3 · 待回填 1`（这一周所有 item 按 kind 计数）
2. 七天网格 `<div className="grid grid-cols-1 gap-1 md:grid-cols-7">`，每一天：
   `<div data-cadence-day={day.day} className={…}>`，类名按是否今天用对象映射：
   - 共用：`flex min-w-0 gap-2 rounded-md p-1.5 md:min-h-24 md:flex-col md:gap-1`
   - 今天：`bg-selected`；其余：`bg-column`
   - 日期头 `<div className="flex w-14 shrink-0 items-baseline gap-1 md:w-auto">`：星期（今天显示「今天」，`text-xs font-medium text-fg`；其余 `day.weekday`，`text-xs text-fg-2`）+ 日期 `day.date`（`text-xs text-fg-2 tabular`）
   - 条目列 `<div className="flex min-w-0 flex-1 flex-wrap gap-1 md:flex-col md:flex-nowrap">`，每个 item：
     `<Link href={`/works/?open=${item.work.id}`} data-cadence-item={item.pub.id} data-kind={item.kind} title={item.work.title} className={…}>`
     共用类 `flex min-w-0 items-center gap-1 rounded-[4px] px-1 py-0.5 text-xs` + `focusRing`；按 kind 映射：
     - published：`bg-card text-fg shadow-xs`
     - planned：`border border-dashed border-line-3 bg-card text-fg-2`
     - pending：`bg-card text-warn shadow-xs`，最前面加 `<span aria-hidden className="size-1.5 shrink-0 rounded-full" style={{ background: "var(--label-amber)" }} />`
     里面：`<PlatformMark platform={item.account.platform} size={12} className="md:mt-px" />` + 标题 span（手机上 `truncate`；`md` 起七列时改成 `line-clamp-2 break-all`，条目容器 `md:items-start`），文字是 `shortTitle(item.work.title)`
3. 图例 `<div className="mt-2 flex flex-wrap items-center gap-3 text-xs text-fg-2">`：
   - 白底小方块（`size-2.5 rounded-[2px] bg-card shadow-xs border border-line`，外面包一层 `inline-flex rounded-[3px] bg-column p-0.5` 的小底，白卡上才看得见）+「已发」
   - 虚线小方块（`size-2.5 rounded-[2px] border border-dashed border-line-3`，同样包一层 `bg-column` 小底）+「排期」
   - 琥珀小圆点（`size-1.5 rounded-full`，`var(--label-amber)`）+「待回填」

**数据**：`weekCadence()`（`@/lib/metrics`）。当前数据：周二 10/6 一条待回填（SaaS 后台那篇的知乎版），周五 10/9 两条排期（Jev 的知乎版、博客 Cloudflare Tunnel 加 Access），周六 10/10 一条排期（小红书卡片），其余天为空；周四 10/8 是今天。

**交互**：条目是链接，点开作品详情。

**状态**：某天没有条目就空着；整周都没有条目时右上角计数换成「这周还没有安排」。

**响应式**：`md` 以下变成一天一行（日期头在左，条目在右换行排）；`md` 起七列。

**文案**：「本周节奏」「已发 / 排期 / 待回填」「今天」。
