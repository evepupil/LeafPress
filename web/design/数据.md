# 数据 `/data/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label`、按钮文字的地方，交互检查会用到，**名字和取值不能改**。

## 第三版改动（最新，以这里为准；和下面第二版、第一版冲突时按这里）

1. **没有手填**：DA4 去掉「手填」按钮、手填弹窗和 `?entry=` 参数。每个号一行（`data-source-row`、`data-source-status`）：方式 · 来源 · 什么时候拉 · 状态；拉取失败的有「重试」（只拉这个号，按接入里现在的配置拉），还没接的写打算怎么拿和「看接入」链接。
2. **B站、小红书的数据还没接**：全部账号的粉丝合计 `5,824`；DA2 分账号里这两行写「数据还没接」。表头「阅读」改叫「浏览」。
3. **DA3 作品排行按平台的数据项**：排序是「浏览 / 互动 / 近 7 天」。看全部账号时列：作品、账号、浏览（各平台主数据）、互动（合计）、近 7 天；只看一个号时，按这个平台自己的数据项一列一列摆（知乎：浏览、点赞、收藏、评论、分享）。
4. **DA0「现在拉一次」**按接入里的配置拉：博客的 Umami 密钥没换就还是「技术博客：统计接口返回 401，其余已入库」；换好了是「全部入库」。

## 第二版改动（以这里为准，和下文冲突时按这里）

1. **公众号整条去掉**：账号只有 4 个。DA1 的账号切换是「全部、知乎、博客、B站、小红书」；DA2 分账号 4 行；DA3 账号下拉「全部账号」+ 4 个；DA4 数据来源 4 行（知乎接口正常；博客统计拉取失败 401；B站手填，上次 9月28日；小红书还没有数据）。
2. **作品排行改成按作品排**（一个作品只对应一个平台，不再有「版本」）：`topPublications` → `topWorks(by, limit, accountId?)`，`item.pub` → `item.work`；表头「版本」改成「账号」，单元格用 `<AccountTag account={item.account} />`；行属性 `data-pub` 改成 `data-work={item.work.id}`；数据格 `metricText(item.work, key)`；作品链接 `/?open=<编号>`。`PubChip` 已删除。
3. **DA4 数据来源最上面加一行定时任务**：`useSchedules((s) => s.runs["data-pull"])`：`<div data-pull-schedule className="flex flex-wrap items-center gap-2 border-b border-line px-3 py-2 text-xs">` + `RunResultIcon` + 「拉作品数据 · 每天 06:00」（`text-fg`）+ `formatRelative(lastRunAt)` + ` · ` + `lastNote`（失败用 `text-bad`）。
4. **DA0「现在拉一次」**改成真跑一次定时工作流：按钮禁用 + 转圈 1.2 秒后 `toast(runSchedule("data-pull"))`（`@/state/actions`），DA4 那一行的时间跟着变成「刚刚」。
5. 数字：全部账号粉丝 `5,872`；全部账号近 4 周阅读 `6.8万`。

本页节奏：视图栏（截至日期 + 现在拉一次）→ 账号切换条 → 主图卡（白卡）→ 下面左侧分账号表、右侧数据来源（两张白卡）→ 作品排行（白卡表格）。
本页核心动作：在主图卡上切换指标和账号。
本页最重要的区块：DA1 走势，允许写得最长。

## DA0 现在拉一次 `src/features/data/pull-now.tsx`（`"use client"`）

**外层**：直接返回一个按钮。

**元素**：`<Button variant="outline" size="sm" data-pull-now disabled={pulling} onClick={…}>`，平时 `<RefreshCw />现在拉一次`；拉取中 `<LoaderCircle className="animate-spin" />拉取中`。

**数据**：无。

**交互**：`pulling: boolean`。点了 `pulling = true`，1200 毫秒后（`setTimeout`，组件卸载时清掉）`pulling = false`，并 `toast.warning("知乎已更新到 10月7日；博客统计还是返回 401")`（日期用 `formatDay(LATEST_DAY)` 拼）。

**状态**：拉取中禁用。

**响应式**：手机只显示图标：文字放在 `<span className="hidden sm:inline">` 里，按钮加 `aria-label="现在拉一次"`。

**文案**：「现在拉一次」「拉取中」。

## DA1 走势 `src/features/data/trend.tsx`（`"use client"`）—— 本页最重要

**外层**：`<div id="trend" className="flex min-w-0 flex-col gap-2">`。

**元素**：
1. 账号切换条 `<div className="no-scrollbar -mx-0.5 overflow-x-auto px-0.5" data-trend-scope>` 里放 `<Segmented label="看哪个号" value={scope} onChange={setScope} options={[{ value: "all", label: "全部" }, …5 个账号]} />`，账号选项的文字是平台名：知乎、博客、公众号、B站、小红书（顺序同 `ACCOUNTS`）
2. `<MetricChartCard key={scope} scope={scope} />`（换账号时重新挂载，页签回到「粉丝」）

**数据**：主图卡自己算。全部账号：粉丝 9,129（近 12 周 +16%），近 12 周阅读 12.1万；知乎：关注者 5,510。

**交互**：`scope: string`，默认 `"all"`。

**状态**：由主图卡负责。

**响应式**：切换条在手机上横向滚动。

**文案**：「看哪个号」「全部」及平台名。

**元素**：

**交互**：账号链接。

**状态**：阅读为 0 的号互动率「—」，阅读涨跌「—」。

**响应式**：表格横向滚动。

**文案**：「分账号」「近 7 天」「账号」「粉丝」「7 天」「30 天」「阅读」「互动率」「合计」。

## DA3 作品排行 `src/features/data/top-works.tsx`（`"use client"`）

**外层**：`<section id="top" aria-labelledby="top-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`。

**元素**：
1. 标题行 `flex flex-wrap items-center gap-2 border-b border-line px-3 py-2`：`<ChartColumn className="size-4 text-fg-2" aria-hidden />` + `<h2 id="top-title" className="text-sm font-medium">作品排行</h2>` + 右边 `ml-auto flex items-center gap-2`：账号 `Select`（触发器 `h-6 w-auto text-xs`，`data-top-account`，「全部账号」+ 5 个账号）+ `<Segmented label="排序" value={by} onChange={setBy} options={[{ value: "reads", label: "阅读" }, { value: "interactions", label: "互动" }, { value: "growth", label: "近 7 天" }]} />`（外包 `<div data-top-sort>`）
2. 表格外包 `<div className="overflow-x-auto">`，`<table className="w-full min-w-[820px] text-sm">`，表头同上：「#」「作品」「版本」「阅读」「赞同」「收藏」「评论」「近 7 天」
   每行 `<tr data-top-row data-pub={item.pub.id} className="h-10 border-t border-line hover:bg-hover">`：
   - 名次 `w-8 text-xs text-fg-2 tabular`
   - 作品：`<Link href={`/works/?open=${item.work.id}`} className={cn("block max-w-[320px] truncate", focusRing)}>{item.work.title}</Link>`

**交互**：`by: RankBy` 默认 `"reads"`；`account: string` 默认 `"all"`。

**状态**：没有数据（比如选了 B站）时表格位置显示 `<EmptyState icon={ChartColumn} title="这个号还没有发布数据" />`。

**响应式**：表格横向滚动；标题行在手机上换行。

**文案**：「作品排行」「全部账号」「阅读 / 互动 / 近 7 天」「#」「作品」「版本」「阅读」「赞同」「收藏」「评论」「近 7 天」。

## DA4 数据来源 `src/features/data/sources.tsx`（`"use client"`）

允许拆子组件 `sources-*.tsx`（例如 `sources-entry-dialog.tsx`），状态放在主文件。

**外层**：`<section id="sources" aria-labelledby="sources-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`。

**状态**：

```ts
overrides: Record<string, IsoTime>   // 手填后记下的时间（用 DEMO_NOW）
entryFor: string | null               // 手填弹窗对应的账号；地址栏 entry 参数是 manual 账号时打开
form: { followers: string; reads: string; interactions: string }
```

**元素**：
1. 标题行 `flex h-10 items-center gap-2 border-b border-line px-3`：`<Database className="size-4 text-fg-2" aria-hidden />` + `<h2 id="sources-title" className="text-sm font-medium">数据来源</h2>`
2. 列表 `<ul className="divide-y divide-line">`，每个账号：
   `<li data-source-row={a.id} className="flex min-w-0 flex-col gap-1.5 px-3 py-2.5">`
   - 第一行 `flex min-w-0 items-center gap-2`：`<AccountTag account={a} size="md" showPlatform />` + 右边 `ml-auto` 动作：
     - mode 为 manual：`<Button variant="outline" size="sm" data-source-entry onClick={() => 打开弹窗(a.id)}>手填</Button>`
     - 拉取失败：`<Button variant="outline" size="sm" data-source-retry onClick={…}>重试</Button>`，点了 `toast.warning("还是返回 401，先到 Umami 后台换密钥")`
     - 其余：不放按钮
   - 第二行 `flex min-w-0 flex-wrap items-center gap-x-3 gap-y-1 text-xs text-fg-2`：`{DATA_MODE_LABEL[mode]} · {provider}`、`<span className="inline-flex items-center gap-1"><Clock className="size-3" aria-hidden />{schedule}</span>`、`<SourceBadge source={有覆盖时 { ...dataSource, lastPullAt: 覆盖时间, lastResult: "ok" } : dataSource} />`
   - 拉取失败时第三行 `text-xs text-bad`：`{failReason}。{fixHint}`
3. 手填弹窗 `<Dialog open={entryFor !== null} …>`，`<DialogContent data-entry-dialog>`：
   - `<DialogTitle>手填 · {accountLabel(账号)}</DialogTitle>`
   - 表单 `grid gap-3`：`Field` 标签 `audienceLabel`（`Input id="entry-followers" type="number" inputMode="numeric"`，默认值为当前粉丝数）、`Field` 标签 `本周${readsLabel}`（`id="entry-reads"`，默认空）、`Field` 标签「本周互动」（`id="entry-interactions"`，默认空）、一行 `text-xs text-fg-2`：`记在 {formatDay(TODAY)}`
   - 底部 `<Button variant="outline">取消</Button>` + `<Button data-entry-save onClick={…}>保存</Button>`（粉丝为空时禁用）
   - 保存：`overrides[账号] = DEMO_NOW`，关闭弹窗，`toast.success(\`已记下${账号名}的数据\`)`

**数据**：`ACCOUNTS`、`DATA_MODE_LABEL`、`accountLabel`、`summaryOf`。当前：知乎接口正常（今天 06:00）；博客统计拉取失败（401）；公众号、B站手填（上次 9月28日）；小红书还没有数据（手填）。

**交互**：见上；地址栏 `entry=<账号编号>` 只在该账号是手填方式时打开弹窗，只读一次，关闭弹窗时 `router.replace("/data/")`。

**状态**：表单数字框只接受数字（`type="number"`）；`never` 显示「还没有数据」。

**响应式**：一列；第二行在手机上换行。

**文案**：「数据来源」「手填」「重试」「记在」「本周互动」「取消」「保存」，以及上面两条 toast。
