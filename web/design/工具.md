# 工具 `/tools/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label`、按钮文字的地方，交互检查会用到，**名字和取值不能改**。

本页节奏：视图栏 → 工具卡片网格（白卡）→ 下面左侧运行记录（白卡列表 + 右侧滑出的详情抽屉）、右侧录屏成片流水线（白卡）。
本页核心动作：在工具卡片里找到工具，复制「在 Claude Code 里怎么说」。
本页最重要的区块：T1 工具卡片，允许写得最长。

工具只在 Claude Code 里发起（网页不直接跑工具），所以卡片上最重要的是「怎么说」和最近的运行结果。

## T1 工具卡片 `src/features/tools/tool-grid.tsx`（`"use client"`）—— 本页最重要

**外层**：`<section id="tools" aria-labelledby="tools-title">`（不加底色）。

**元素**：
1. 标题行 `<div className="flex flex-wrap items-center gap-2 pb-1">`：`<h2 id="tools-title" className="text-sm font-medium">工具</h2>` + `<span className="text-sm text-fg-2 tabular" data-tools-count>{当前显示个数}</span>` + 右边 `ml-auto` 的 `<Segmented label="按状态筛选" value={filter} onChange={setFilter} options={[{ value: "all", label: "全部" }, { value: "ready", label: "可用" }, { value: "needs-setup", label: "需配置" }, { value: "planned", label: "规划中" }]} />`（外包 `<div data-tools-filter>`）
2. 网格 `<div className="grid gap-(--gap-card) sm:grid-cols-2 xl:grid-cols-3">`，每个工具一张卡（顺序同 `TOOLS`）：
   `<article data-tool-card={tool.id} data-status={tool.status} className="flex min-w-0 flex-col gap-2.5 rounded-lg border border-line bg-card px-4 py-3 shadow-sm">`
   - 头部 `flex min-w-0 items-center gap-2.5`：图标方块 `<span className="flex size-7 shrink-0 items-center justify-center rounded-md bg-column text-fg-2">` + 图标（`size-4`，按 `tool.icon` 对象映射：send → `Send`，message → `MessageSquare`，pen → `PenLine`，notebook → `NotebookPen`，images → `Images`，newspaper → `Newspaper`，video → `Clapperboard`，cards → `LayoutGrid`，download → `CloudDownload`，report → `ScrollText`）；名字 `<h3 className="min-w-0 truncate text-sm font-medium">`；右边 `ml-auto flex shrink-0 items-center gap-1 text-xs text-fg-2`：`<ToolStatusIcon status={tool.status} />` + `TOOL_STATUS_LABEL[status]`
   - 说明 `<p className="line-clamp-2 text-sm text-fg-2">{tool.summary}</p>`
   - 步骤 `<ol className="flex flex-wrap items-center gap-1 text-xs text-fg-2" aria-label="步骤">`：每步 `<li className="flex items-center gap-1">`，第二步起前面加 `<ChevronRight className="size-3 text-fg-3" aria-hidden />`，步骤名放在 `<span className="rounded-[4px] bg-column px-1.5 py-0.5">` 里
   - 平台与产出 `flex min-w-0 items-center gap-1.5 text-xs text-fg-2`：每个平台 `<PlatformMark platform size={14} />` + `<span className="truncate">产出：{tool.outputs}</span>`
   - 怎么说 `<div className="flex min-w-0 items-center gap-2 rounded-md bg-raised px-2 py-1.5">`：`<Bot className="size-3.5 shrink-0 text-fg-3" aria-hidden />` + `<span className="min-w-0 flex-1 truncate text-xs" data-tool-say>「{tool.say}」</span>` + `<IconButton label="复制说法" size="icon-xs" data-tool-copy onClick={…}><Copy /></IconButton>`
   - 有 `command` 时再加一行同样的盒子：`<Terminal …/>` + `<span className="min-w-0 flex-1 truncate font-mono text-xs text-fg-2">{tool.command}</span>` + `IconButton`（label「复制命令」）
   - 需配置时 `<p className="flex items-start gap-1.5 text-xs text-warn"><TriangleAlert className="mt-px size-3.5 shrink-0" aria-hidden />{tool.setupHint}</p>`
   - 底行 `mt-auto flex flex-wrap items-center gap-x-3 gap-y-1 border-t border-line pt-2 text-xs text-fg-2`：`<span className="tabular" data-tool-runs>本月 {runsThisMonth} 次</span>`；有 `lastRun` 时 `<Link href={`/tools/?run=${lastRun.id}`} className="inline-flex items-center gap-1 hover:text-fg"><RunStateIcon state={lastRun.state} size={12} />{formatRelative(lastRun.startedAt)}</Link>`；没有时「还没跑过」；有 `schedule` 时 `<span className="inline-flex items-center gap-1"><Clock className="size-3" aria-hidden />{tool.schedule}</span>`

**数据**：`TOOLS`、`toolStats`（`@/lib/metrics`）、`TOOL_STATUS_LABEL`。期望：博客改投知乎「本月 2 次」，最近一次运行中；可用 7 个、需配置 2 个、规划中 1 个。

**交互**：`filter: "all" | ToolStatus`，默认 `"all"`。复制按钮调 `copyText`（`@/lib/platform`），成功 `toast.success("已复制")`。

**状态**：筛选后为空 `<EmptyState icon={Workflow} title="没有这一类工具" />`；说明、说法过长截断。

**响应式**：手机一列，`sm` 两列，`xl` 三列；卡片等高，底行贴底（`mt-auto`）。

**文案**：「工具」「全部 / 可用 / 需配置 / 规划中」「产出：」「复制说法」「复制命令」「本月 N 次」「还没跑过」「已复制」。

## T2 运行记录 `src/features/tools/run-list.tsx`（`"use client"`）

允许拆子组件 `run-list-*.tsx`（例如 `run-list-sheet.tsx`），状态放在主文件。

**外层**：`<section id="runs" aria-labelledby="runs-title" className="overflow-hidden rounded-lg border border-line bg-card shadow-sm">`。

**状态**：

```ts
filter: "all" | "waiting" | "running" | "failed"     // 默认 "all"；地址栏 state 参数是这三个之一时用它
openId: string | null                                 // 地址栏 run 参数指向存在的运行时打开
runs: ToolRun[]                                       // 初始为 RUNS 的深拷贝，抽屉里的操作改它
backfill: string                                      // 回填链接输入框
```

读 `useSearchParams()` 的 `state`、`run`，首次渲染按参数初始化，之后参数变化也跟着变（工具卡片的「最近一次运行」、侧栏「等我处理」都会在本页改地址）；`run` 变空时关抽屉，`state` 变空时不重置筛选；关闭抽屉时只在地址栏带参数时 `router.replace("/tools/", { scroll: false })`。

**元素**：
1. 标题行 `flex h-10 items-center gap-2 border-b border-line px-3`：`<History className="size-4 text-fg-2" aria-hidden />` + `<h2 id="runs-title" className="text-sm font-medium">运行记录</h2>` + `<span className="text-sm text-fg-2 tabular" data-runs-count>{当前显示条数}</span>` + 右边 `ml-auto` 的 `<Segmented label="按状态筛选" value={filter} onChange={…} options={[{ value: "all", label: "全部" }, { value: "waiting", label: "等你处理" }, { value: "running", label: "运行中" }, { value: "failed", label: "失败" }]} />`（外包 `<div data-runs-filter>`）
2. 列表 `<ul className="divide-y divide-line">`，每条：
   `<li><button type="button" data-run-row={run.id} data-state={run.state} onClick={() => setOpenId(run.id)} className={cn("flex w-full min-w-0 items-center gap-3 px-3 py-2 text-left hover:bg-hover", focusRingInset)}>`
   - `<RunStateIcon state={run.state} />`
   - `<div className="min-w-0 flex-1">`：`run.title`（`truncate text-sm`）；第二行 `truncate text-xs text-fg-2`：`{toolName(run.toolId)} · {RUN_STATE_LABEL[state]}`，等你处理时再加 ` · {run.waitingFor}`
   - 步骤进度 `<div className="flex shrink-0 items-center gap-1.5">`：`<span className="text-xs text-fg-2 tabular">{完成步数}/{总步数}</span>` + `<span className="flex gap-0.5" aria-hidden>`，每步一个 `<span className="h-1 w-1.5 rounded-full" style={{ background: 颜色 }} />`，颜色按步骤状态映射：done → `var(--chart-ink)`，running / waiting → `var(--progress)`，failed → `var(--risk)`，pending → `var(--line-strong)`
   - 时间 `hidden w-20 shrink-0 text-right text-xs text-fg-2 sm:block`：`formatRelative(run.startedAt)`
3. 详情抽屉 `<Sheet open={openId !== null} onOpenChange={…}>`，`<SheetContent side="right" className="gap-0 p-0 data-[side=right]:w-full data-[side=right]:sm:max-w-[480px]" data-run-sheet>`（覆盖宽度要带 `data-[side=right]` 前缀）：
   - 头部 `border-b border-line px-4 py-3`：`flex items-center gap-2`（`<RunStateIcon />` + `<SheetTitle className="text-sm font-medium" data-run-sheet-title>{run.title}</SheetTitle>`）；第二行 `mt-1 text-xs text-fg-2`：`{toolName} · {RUN_STATE_LABEL} · 开始于 {formatRelative(startedAt)}`，有 `finishedAt` 时加 ` · 用时 {formatDuration(startedAt, finishedAt)}`
   - 等你处理的提示 `<div className="mx-4 mt-3 rounded-md bg-raised px-3 py-2.5" data-run-waiting>`：第一行 `text-sm`：`等你：{run.waitingFor}`；下面按工具不同放动作：
     - `blog-to-zhihu`：`<form className="mt-2 flex gap-1.5">` + `<Input data-run-backfill aria-label="粘贴链接" placeholder="粘贴知乎文章链接" className="h-7" />` + `<Button type="submit" size="sm" data-run-backfill-submit disabled={!backfill.trim()}>登记</Button>`。提交：等待的那一步改 done（note「已回填」，at 用 `DEMO_NOW`），运行改 done（`finishedAt` 用 `DEMO_NOW`，去掉 `waitingFor`），`toast.success("已登记，知乎版本改为已发")`
     - `video-pipeline`：`<Button size="sm" className="mt-2" data-run-confirm>字幕校对完了</Button>`。点了：等待的那一步改 done，下一步改 running，运行改 running，`toast.success("字幕已确认，继续出片")`
     - `zhihu-writing`：先显示大纲预览 `<ol className="mt-2 list-decimal pl-5 text-sm">`，五条：「一稿多发为什么难」「先登记发布意图，再调平台」「AI 改写和固定转换分开」「发布前作者确认」「数据回来以后怎么用」；再放 `<Button size="sm" className="mt-2" data-run-confirm>确认大纲</Button>`。点了：同上一条的处理，`toast.success("大纲已确认，开始写全文")`
     - `wechat-review`：`<Button variant="outline" size="sm" className="mt-2" asChild><a href={WECHAT_REVIEW_URL} target="_blank" rel="noreferrer">打开审核页<ExternalLink className="size-3" aria-hidden /></a></Button>`
   - 失败的提示 `<div className="mx-4 mt-3 rounded-md bg-raised px-3 py-2.5" data-run-failed>`：`<p className="text-sm text-bad">{run.error}</p>` + `<Button variant="outline" size="sm" className="mt-2" data-run-retry>重试</Button>`。点了：失败的那一步改 running，运行改 running，`toast("已重新开始")`
   - 步骤 `<ol className="flex flex-col px-4 py-3">`，每步 `<li data-run-step className="flex gap-2.5 py-1.5">`：`<StepStateIcon state={step.state} className="mt-0.5" />` + `<div className="min-w-0 flex-1">`（第一行 `flex items-center gap-1.5`：步骤名 `text-sm` + `<span className="rounded-[4px] bg-column px-1 text-xs text-fg-2">{STEP_KIND_LABEL[kind]}</span>`；有 `note` 时第二行 `text-xs text-fg-2`）+ 有 `at` 时右边 `shrink-0 text-xs text-fg-2 tabular` 的 `formatTime(at)`
   - 有 `workId` 时底部 `border-t border-line px-4 py-3 text-sm`：「相关作品」+ `<Link href={`/works/?open=${workId}`} className="hover:underline">{作品标题}</Link>`

**数据**：`RUNS`（11 条）、`TOOLS`、`toolName`、`workById`、`WECHAT_REVIEW_URL`、`RUN_STATE_LABEL`、`STEP_KIND_LABEL`。各筛选的条数：全部 11、等你处理 4、运行中 1、失败 2。

**交互**：见上；操作改的是本组件的 `runs` 状态，列表里的状态图形和进度跟着变。

**状态**：筛选后为空 `<EmptyState icon={History} title="没有这一类运行" />`；地址栏 `run` 参数不存在时不打开抽屉。

**响应式**：手机隐藏时间列，进度保留；抽屉手机全宽。

**文案**：「运行记录」「全部 / 等你处理 / 运行中 / 失败」「等你：」「粘贴知乎文章链接」「登记」「字幕校对完了」「确认大纲」「打开审核页」「重试」「已重新开始」「开始于」「用时」「相关作品」，以及上面几条 toast。

## T3 录屏成片 `src/features/tools/video-pipeline.tsx`（服务端组件）

**外层**：`<section id="video" aria-labelledby="video-title" className="rounded-lg border border-line bg-card px-4 py-3 shadow-sm">`。

**元素**：
1. 标题行 `flex flex-wrap items-center gap-2 pb-2`：`<Clapperboard className="size-4 text-fg-2" aria-hidden />` + `<h2 id="video-title" className="text-sm font-medium">录屏成片</h2>` + `<LabelChip>不用 AI 视频模型</LabelChip>`
2. 正在做 `<div className="rounded-md bg-raised px-3 py-2.5" data-video-current>`：第一行 `flex items-center gap-2`：`<RunStateIcon state="waiting" />` + `<span className="min-w-0 flex-1 truncate text-sm">Cloudflare Tunnel 实现 ssh 穿透 · 录屏版</span>` + `<span className="text-xs text-fg-2 tabular">3/7</span>`；第二行 `mt-2 flex items-center gap-2`：`<ProgressMeter value={3 / 7} className="w-24" />` + `<span className="text-xs text-fg-2">等你校对字幕</span>` + `<Button variant="outline" size="sm" className="ml-auto" asChild><Link href="/tools/?run=run-02">去校对</Link></Button>`（标题、步数、等什么都从 `RUNS` 里编号为 `run-02` 的运行取）
3. 七个阶段 `<ol className="mt-3 flex flex-col">`，每个阶段 `<li data-video-stage className="flex gap-2.5 py-1.5">`：`<StepStateIcon state={…} className="mt-0.5" />` + `<div className="min-w-0 flex-1">`：第一行阶段名 `text-sm`；第二行 `text-xs text-fg-2`：工具名 + 有备注时「 · 备注」。阶段、工具、状态取 `run-02` 的步骤，工具名按下表（写成本文件里的常量）：

   | 阶段 | 工具名 |
   |---|---|
   | 录屏 | OBS 或 Cap |
   | 剪掉没说话的片段 | auto-editor |
   | 生成字幕 | VideoCaptioner + faster-whisper |
   | 你校对字幕 | 人工 |
   | 配音（可选） | IndexTTS-2.5，只有 CPU 时用 edge-tts |
   | 出横版和竖版 | FFmpeg |
   | 投稿 | biliup（还没登录） |

4. 产出 `<div className="mt-2 flex flex-wrap gap-1 border-t border-line pt-2.5">`：三个 `LabelChip`：`<LabelChip icon={<MonitorPlay className="size-3 text-fg-3" aria-hidden />}>横版 16:9 → B站</LabelChip>`、`<LabelChip icon={<Smartphone …/>}>竖版 9:16 → 小红书、抖音</LabelChip>`、`<LabelChip icon={<Captions …/>}>字幕 .srt</LabelChip>`

**数据**：`RUNS` 中的 `run-02`（7 步：3 步完成、1 步等你、3 步未开始）。

**交互**：只有「去校对」链接。

**状态**：找不到 `run-02` 时「正在做」那块换成一行 `text-sm text-fg-2`「现在没有在做的视频」，阶段全部按未开始显示。

**响应式**：一列；放在页面右侧窄栏（`xl` 起占 2/5），手机全宽。

**文案**：「录屏成片」「不用 AI 视频模型」「等你校对字幕」「去校对」、上表工具名、三个产出标签。
