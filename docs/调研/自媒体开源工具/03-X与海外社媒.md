# X 与海外社媒排期工具
> 调研日期：2026-10-01

## 结论
1. **官方 API 是唯一不用担心封号的路，且 2026 年起改为按量计费，没有免费额度**。发一条纯文字推 $0.015，**带链接的推 $0.20**（[官方定价页](https://docs.x.com/x-api/getting-started/pricing)）。委托人推广开源项目必然带链接：每月 300 条带链接推 ≈ **$60/月**；不带链接 ≈ $4.5/月。要不要走官方接口，取决于推文里链接多不多。
2. **工具首选自托管 Postiz**：Star 最多、更新最勤（当天还在提交）、X 推串/配图/视频/统计全支持，官方自带 MCP 服务和 REST API，Claude Code 一行命令接入，最符合「AI 助手驱动」的工作方式。自托管免费，成本只剩 API 按量费用。
3. **Mixpost 别急着上**：开源仓库只是「Lite」版，X 只能发个人号，统计/队列/多平台等核心功能在一次性收费的 Pro（$299）里；主仓库最近一次提交是 2026-03-16，节奏明显慢于 Postiz。
4. **浏览器自动化（baoyu-post-to-x）能用但要克制**：X 官方自动化规则明文「脚本化操作 X 网站可能导致账号永久封禁」（[automation rules](https://help.x.com/en/rules-and-policies/x-automation)）。该 skill 是所有浏览器方案里风险最低的——填好内容后由人手动点发布、不自动定时，适合发长文（X Articles），不适合当定时群发器。
5. **国内平台别指望**：Postiz、Mixpost 的支持列表里都没有知乎、小红书、B站、抖音，一套工具通吃国内外不存在，国内发布得用另外的方案。

## 官方接口收费现状
以 [docs.x.com 定价页](https://docs.x.com/x-api/getting-started/pricing)（2026-10-01 实读）为准，X API v2 现为 **pay-per-usage（按量计费、买额度扣费、无订阅）**，入口是 [console.x.com](https://console.x.com)：

| 项目 | 单价（官方页原文） |
| --- | --- |
| 发推（Post: Create） | $0.015 / 次 |
| 发推（带 URL） | **$0.200 / 次** |
| 读推文 | $0.005 / 条 |
| 读自己的数据（Owned Reads） | $0.001 / 条 |
| 读用户 / 粉丝关系 | $0.010 / 条 |
| 同一资源 24 小时内重复请求 | 去重、不重复扣费 |
| 累计消费 $200+/月 | 返 10%–20% xAI API 额度 |

- **免费额度**：官方定价页未列任何免费档。第三方报道一致称旧 Free 档（500 写/月）已于 2026-02-06 停止新开、全面转向按量计费（[GIGAZINE 报道](https://gigazine.net/gsc_news/en/20260209-x-api-pay-per-use/)、[roboin 报道](https://roboin.io/article/en/2026/02/08/x-transitions-api-to-pay-per-use-model-ending-free-plan/)）；旧 Basic（$200/月）、Pro（$5000/月）档已不对新开发者开放。这些细节官方页面未逐字核实，档位取消这一点有多方交叉印证。
- **官方自动化规则**（[X automation rules，2026-04 更新版实读](https://help.x.com/en/rules-and-policies/x-automation)）：允许经 API 自动发内容（含 RSS 转发）；**禁止**「非 API 形式的自动化，例如脚本化操作 X 网站……可能导致账号永久封禁」；自动点赞、批量关注被明令禁止；AI 自动回复机器人需事先获得 X 书面批准。
- 官方在按量计费发布时同步提供了 XDK（官方 Python/TS SDK）、Playground 和**官方 MCP 服务**（[官方 changelog](https://x-preview.mintlify.app/changelog)）。

**每月大概花多少钱（个人发几百条）**：300 条纯文字 ≈ $4.5；300 条带链接 ≈ $60；再加统计读取几美元以内。对「技术内容+项目链接」的场景， realistic 预算是 **$30–70/月**。

## 工具逐个说明

### Postiz（开源排期工具里的事实标准，AI 代理友好度最高）
- 地址：https://github.com/gitroomhq/postiz-app
- 形态：自托管网页服务（Docker），附官方 MCP 服务、公开 REST API、Node SDK、n8n 节点
- 覆盖平台：X、Instagram、YouTube、LinkedIn、Reddit、TikTok、Facebook、Pinterest、Threads、Dribbble、Slack、Discord、Mastodon、Bluesky（README 平台图标列表）。**无知乎/小红书/B站/抖音**（Issue 区搜索未见到支持计划）。
- 实现方式：官方接口（各平台 OAuth 开发者应用）
- AI 助手能否调用：**能，且是一等公民**。官方 MCP 服务 9 个工具（列渠道、排期、发图/视频），Claude Code 一条命令接入：`claude mcp add postiz --transport http --url https://api.postiz.com/mcp/<key>`（[MCP 文档](https://docs.postiz.com/mcp/setup)）；自托管实例同样有 Public API + MCP。
- X 功能：推串（composer 里逐条追加、支持 CSV 批量排期）、每推最多 4 图、1 视频、单推级别统计（impressions/likes/reposts/replies/quotes/bookmarks）汇总到账号面板（[postiz.com/channels/x](https://postiz.com/channels/x)）
- 自托管资源：官方在 2 vCPU / 2 GB 内存的 Ubuntu 虚拟机上全栈实测可跑；≤20 人小团队建议 4 vCPU / 8 GB。组件：PostgreSQL + Redis + Temporal（[系统要求](https://docs.postiz.com/self-host/installation/system-requirements)、[Docker Compose 指南](https://docs.postiz.com/self-host/installation/docker-compose)）。Windows 上经 Docker Desktop / WSL2 跑。
- 云版：Postiz Cloud $29–99/月（Standard 5 渠道 / Team 10 / Pro 30 / Ultimate 100），（[官方套餐页](https://docs.postiz.com/cloud/plans)）
- 开源协议：AGPL-3.0
- 活跃度：**36,570 Star**，最近提交 **2026-10-01**（当天），未归档（`gh api repos/gitroomhq/postiz-app`）
- 已知坑：升级 Temporal 后定时任务曾大面积失灵、带媒体的定时帖不发出（[Issue #1259](https://github.com/gitroomhq/postiz-app/issues/1259)，2026-06 仍在更新）；添加渠道报 "Could not add provider"（[Issue #918](https://github.com/gitroomhq/postiz-app/issues/918)）；2GB 小机从源码构建会 OOM，建议直接用官方镜像（[官方排障文档](https://github.com/gitroomhq/postiz-docs/blob/main/troubleshooting/self-host.mdx)）
- 对委托人的价值：**高** —— 唯一同时满足「自托管免费 + MCP/API 可被 Claude Code 调用 + X 全功能」的方案。
- 出处：README（实读）、[docs.postiz.com](https://docs.postiz.com)、`gh api` 元数据

### Mixpost（Laravel 系自托管排期，开源部分是 Lite 引流版）
- 地址：https://github.com/inovector/mixpost
- 形态：自托管网页服务（Laravel 包或 Docker），官方有 MCP 服务文档（[docs.mixpost.app/mcp](https://docs.mixpost.app/mcp/tools)）
- 覆盖平台：共 12 个：Facebook、Instagram、LinkedIn、X、TikTok、YouTube、Pinterest、Threads、Bluesky、Mastodon、Pixelfed、Google Business（[官网](https://mixpost.app/social-media-automation)）。**Lite 免费版只支持 X 个人号、Facebook Page、Mastodon**，其余平台和高级统计都在 Pro（[第三方评测转述官方页](https://www.itechguides.com/best/social-media-management-tools/mixpost/)）。**无知乎/小红书/B站/抖音**。
- 实现方式：官方接口
- AI 助手能否调用：能（官方 MCP + API），但 MCP 是否需要 Pro 授权未在免费文档中核实。
- X 功能：单推/推串、配图和视频、定时队列、日历（[mixpost.app/x](https://mixpost.app/x)）；高级统计仅 Pro。
- 自托管资源：PHP ≥ 8.3 + MySQL + Redis 6.2+（[官方服务器配置页](https://docs.mixpost.app/server/)）；第三方教程按 1–2 GB 内存 VPS 部署（[codecope 教程](https://codecope.org/how-to-self-host-mixpost-using-docker)）。比 Postiz 轻。
- 云版：Mixpost Cloud = Pro 托管版（[官方 Cloud 文档](https://docs.mixpost.app/cloud/)，具体月价未在页面抓到，见「拿不准」）
- 开源协议：MIT（仓库本体），但属 open-core：Pro/Enterprise 闭源收费，Pro $299 / Enterprise $1,199 一次性（[mixpost.app/pricing](https://mixpost.app/pricing)）
- 活跃度：**3,749 Star**，最近提交 **2026-03-16**（约 6 个月前），未归档（`gh api` 元数据）
- 已知坑：定时帖在 LinkedIn 和 X 上被截断（[Issue #169，已修复](https://github.com/inovector/mixpost/issues/169)）；OAuth 回调反射型 XSS（[Issue #204，open](https://github.com/inovector/mixpost/issues/204)）
- 对委托人的价值：**中** —— 想要轻量 LAMP 栈可考虑，但 X 深度功能锁在付费 Pro，更新节奏和 AI 生态都不如 Postiz。
- 出处：README（实读）、官网与文档（实读/检索）、`gh api` 元数据

### baoyu-skills · baoyu-post-to-x（浏览器自动化 skill，发 X 长文章最省事）
- 地址：https://github.com/JimLiu/baoyu-skills（skill：`skills/baoyu-post-to-x`）
- 形态：AI 助手 skill（Claude Code / Codex 等），配套 TypeScript 脚本，用 bun/npx 运行
- 覆盖平台：仅 X（另有 baoyu-post-to-wechat 等姊妹 skill）
- 实现方式：**借用已登录的真实 Chrome**（三种模式：Codex Chrome 插件 / Chrome Computer Use / CDP 脚本兜底），内容填进浏览器后**由用户手动点发布**——skill 明文规定「未经用户明确确认，绝不点击 Publish/Post」（SKILL.md 实读）
- AI 助手能否调用：**能，本身就是为 AI 助手设计的 skill**，`npx skills add jimliu/baoyu-skills` 安装
- 功能：文字/图片/视频推文、引用推、**X Articles 长文章**（Markdown → 富文本粘贴 + 正文配图逐张上传）；**无定时、无统计**
- 自托管资源：无需服务端，本机 Chrome + Node/bun 即可；走本机代理访问 X，与委托人现有网络环境吻合
- 开源协议：MIT（仓库级；经 ClawHub 发布的单个 skill 为 MIT-0）
- 活跃度：**26,246 Star**（整个 baoyu-skills 仓库），skill 版本 v1.58.1，最近提交 **2026-09-10**，未归档（`gh api` 元数据）
- 已知坑：依赖 X 页面 `data-testid`/DOM 结构，X 改版即失效；**违反 X 自动化规则的风险由用户自担**（规则原文见上）；CDP 模式在 Windows 上需允许剪贴板/文件权限（SKILL.md 内置排障步骤）
- 对委托人的价值：**中高** —— 零 API 费用、零服务端，适合「AI 写好 → 人确认 → 发出」的人工节奏；不能定时，别批量自动化。
- 出处：[SKILL.md 实读](https://github.com/JimLiu/baoyu-skills/tree/main/skills/baoyu-post-to-x)、README 实读、`gh api` 元数据

### X 官方 API + 自选 MCP（直连官方，无中间层）
- 地址：[docs.x.com](https://docs.x.com/x-api/getting-started/about-x-api)；官方 XDK（Python/TS SDK）、Playground、官方 MCP 见 [changelog](https://x-preview.mintlify.app/changelog)
- 形态：官方接口 / MCP 服务
- 覆盖平台：仅 X
- 实现方式：官方接口（pay-per-use 扣费）
- AI 助手能否调用：能（官方 MCP + SDK）
- 活跃度：官方维护
- 对委托人的价值：**中** —— 简单场景（AI 写完直接发/发推串）其实不需要 Postiz 这种平台，官方 MCP/SDK + cron 就够；缺定时队列和统计面板，这些要自己拼。
- 出处：官方文档（实读）

## 拿不准的点
- **Mixpost Cloud 的月费**：官方定价页只实读到自托管 Pro $299 / Enterprise $1,199 一次性价，云版月价未直接读到，未核实。
- **旧 Free 档（500 写/月）取消的确切日期（2026-02-06）和存量用户 $10 代金券**：来自多家第三方报道互相印证，官方页面未逐字核实（官方页只写 pay-per-use 现行价）。
- **Pay-per-use 是否有月度请求上限（post cap）**：官方文档站有 post-cap 页面的引用片段，但细节页未读全，用之前应在 console.x.com 确认。
- **Postiz 定时发布的稳定性**：Issue #1259 反映 Temporal 化之后带媒体的定时帖曾不稳定（2026-06 仍在跟进），最新版是否彻底修复未核实。
- **Mixpost MCP 是否需要 Pro 付费**：文档存在（docs.mixpost.app/mcp），授权要求未核实。
- **baoyu-post-to-x 在 Windows 上的实际兼容性**：SKILL.md 面向 macOS/通用环境编写，Windows 剪贴板/文件上传路径未逐项核实。
