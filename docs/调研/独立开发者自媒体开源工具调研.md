# 独立开发者自媒体开源工具调研

> 调研日期：2026-10-01
> 适用情况：做技术内容（AI 编程、Cloudflare 部署、自己的开源项目），知乎是主阵地，要扩到小红书、B站、抖音，X 可选；内容由 AI 起草、自己写 skill 把关；视频不露脸录屏；电脑是 Windows。
> 分类明细：[自媒体开源工具/](自媒体开源工具/) 下 14 份，每份都有逐个工具的说明和出处链接。本文只放结论和选择。

读前说明（文中反复出现的几个词）：

- **skill**：给 AI 助手的操作手册，装进 Claude Code 后它就知道怎么用某个工具。
- **MCP**：让 AI 助手直接调用外部工具的标准接口。
- **模拟浏览器操作**：用程序替你在网页上点按钮、填表单，平台看来就像真人在操作。
- **逆向接口**：破解平台网页内部用的接口，没有官方授权，平台随时能封。
- **自托管**：装在自己的服务器或电脑上跑。
- **星数**：GitHub 上的收藏数，粗略代表热度，不代表质量。
- **开源协议**：MIT、Apache 基本随便用（包括商用）；GPL、AGPL 也能用，但改了代码再分发或拿来对外提供服务，要把代码公开。

## 一、先说结论

1. **发布这一步，国内只有知乎给个人开了官方接口。** 小红书的官方开放平台没有发笔记的能力；抖音、B站的发布接口只对企业开放。其余平台只能用模拟浏览器操作的开源工具，能用，但都有封号风险，小红书已经明确会封禁「全程 AI 托管」的账号。最稳的分工是：选题、写稿、做图、做视频交给 AI 全自动，发布前人看一眼再点确认。
2. **内容生产这一侧，开源工具已经很成熟。** 字幕、配音、代码截图、小红书卡片、讲解动画都有能让 Claude Code 直接调用的工具，不少还自带官方 skill。这一侧值得多投入。
3. **去 AI 味有现成的中文规则库可以直接抄进你的 skill。** 检测工具误判多，只能参考，不能当验收标准。没有任何平台公开说过「读起来像 AI 就限流」，平台真正处罚的是「用了 AI 不声明」和「批量低质、全程托管」。
4. **有 AI 参与就声明。** 国家规定从 2025 年 9 月起要求发布者主动标识 AI 生成内容，四个国内平台都有声明入口。在知乎的代价是：声明了「包含 AI 辅助创作」的内容不进创作者收益计划（致知计划）。你的目的是获客，这点影响不大，但要你拍板。
5. **把多个平台的账号数据汇总到一张表，目前没有能用的开源工具。** 只能各平台后台看，或者用新榜、蝉妈妈、千瓜这类商业工具。

## 三、分平台

### 知乎（主阵地）

知乎有两条官方通路，你现在只用了「写」那一条。下面的额度和门槛都另派一路核实过官方页面。

| 用途 | 官方入口 | 个人能用吗 | 额度 |
|---|---|---|---|
| 发文章、提问、想法 | openapi.zhihu.com（zhihu-publisher 在用） | 能 | 每天最多 50 次；没有「写回答」的接口 |
| 搜索、热榜、问题推荐、自己账号和单篇的数据 | [知乎数据开放平台](https://developer.zhihu.com/) | 能，知乎账号登录后生成密钥即可，不要企业资质 | 官方首页写注册送每天 5000 次；单个接口另有上限：问题推荐每天 100 次，创作数据每天 200 次，没实名认证的每天 10 次。超出按千次付费：知乎搜索 20 元、热榜 10 元 |

建议：

- **补上「找值得回答的问题」和「回看数据」。** 数据开放平台给每个接口都配了官方的 MCP 和 Skill，另有一个官方命令行工具 Zhihu CLI，直接装官方的就行。第三方的 klarkxy/zhihu-search 把全部接口包好了，但只有 17 星，当参考。
- **「按关键词找浏览多、回答少的问题」没有现成工具。** 用官方搜索拉结果，再按回答数筛一遍，工作量很小，适合写进你写作 skill 的选题步骤。
- **规则：** 发 AI 辅助的内容，在「创作声明」里勾选「包含 AI 辅助创作」。知乎 2023 年的官方公告写明不声明会被限制流通；政府网转述过知乎负责人的说法，被检测出来还可能被打标、排序靠后、折叠，甚至删除封号。勾了之后这篇不进致知计划收益（官方规则原文核实过）。

### 小红书

- **官方没有发笔记的接口**，也没有官方 MCP 或 skill。三个开放平台分别管电商、第三方登录、广告投放。
- **2026-03-10 起：** 用 AI 托管工具注册、发布、互动的账号，或主页全部笔记都是 AI 托管代发的账号，直接封禁；普通账号偶尔用，警告或限流。公告点名平台监测到有人用 OpenClaw 这类工具全程自动化。自己电脑上用脚本或 AI 助手代发算不算「托管」，公告没有定义。
- **发布工具：** XiaohongshuSkills（3.5k 星，驱动你电脑上真实的 Chrome，只支持 Windows，功能最全，还能导出数据看板），或 xiaohongshu-mcp（1.6 万星，有 Windows 程序，Issue 里封号案例不少）。用法：先拿小号跑通，低频发，每篇人过一遍再发。
- **卡片：** Auto-Redbook-Skills 的排版脚本（`render_xhs.py`），默认出 1080×1440 竖图，8 套主题，中文字体可控。仓库没有写开源协议，商用前要问作者；它自带的发布脚本别用。
- **硬性限制：** 标题 20 字、正文 1000 字（官方文档）；图片最多 18 张（只有第三方说法）。

### B站（下一步重点）

- **官方开放平台只收企业法人**，文档写明暂未开通个人开发者入驻。
- **2026 年 B站在系统性清理逆向接口：** 接口文档项目 bilibili-API-collect 1 月被发函关停；最常用的 Python 库 bilibili-api 7 月收到律师函后归档删码。这两个仓库的归档状态我在 GitHub 上核对过。基于它们的 MCP 都别用。
- **投稿用 biliup：** 5.5k 星，MIT，还在更新；标题、简介、标签、分区、封面、分P、定时发布、合集都能设；自带官方 skill（`npx skills add biliup/biliup`），有 Windows 安装包。它同样走逆向接口，目前没有公开收到律师函，长期风险要留意。social-auto-upload 也带 B站上传 skill，可以当备选。
- **专栏、图文动态：** 没有安全可用的自动发布工具，手动发。
- **看评论、找选题：** XZXZZX-Ai/bilibili-mcp，只读字幕、评论、搜索，风险低。

### 抖音

- **官方发布接口个人用不了。** 要求企业主体、注册资本 50 万以上、成立满 1 年，应用类型限创作工具、社区、硬件配套、游戏；个人主体只能建小程序、小游戏、小玩法（官方原文核实过）。
- **工具都是模拟浏览器操作创作者中心，** 绕不开滑块和短信验证：
  - 视频：social-auto-upload 的抖音 skill（1.5 万星），或 lancelin111/douyin-mcp-server（35 星，Skill 和 MCP 两种形态，扫码登录后能复用）。
  - 图文（多图）：chengyi-ai/douyin-image-post-scheduler（100 星，批量加定时的 skill）。
- **规则：** 多账号批量发同质内容（矩阵号）、群控工具、非法脚本都在明确打击范围；AI 内容要用抖音自己的标识功能加标，不加的会被平台打上「疑似使用了AI生成技术」。

### X（可以放最后）

- **官方接口 2026 年起按条收费，没有免费额度：** 每条推 0.015 美元，带链接的每条 0.2 美元（我亲自核对了[官方定价页](https://docs.x.com/x-api/getting-started/pricing)）。推广开源项目大多带链接，每月 300 条大约 60 美元。
- **工具：** Postiz 自托管（3.7 万星，AGPL，自带 MCP，长推串、配图、视频、数据统计都有，需要一台 2GB 内存以上、能跑 Docker 的服务器），自托管免费，成本只剩接口费。
- **省钱方案：** baoyu-skills 里的 baoyu-post-to-x，用浏览器帮你填好内容，你手动点发布。X 官方规则写明「脚本化操作网站可能导致永久封禁」，所以只适合人点发布的节奏。
- Postiz、Mixpost 都不支持国内平台，国内外没有一套工具能通吃。

### 一稿多发

- **Wechatsync v2：** 覆盖知乎文章、小红书长文、抖音图文、B站专栏、X；借用你浏览器里的登录状态，默认只存草稿；有命令行、MCP、Claude Code skill。2026 年初才重写，小红书长文还有没修的 bug。最贴合「AI 推草稿、人确认发布」的流程。
- **MultiPost：** 50 多个平台，同类里最活跃；开源的只有浏览器插件，让 AI 调用要走它的云端接口或闭源桌面端。
- **ArtiPub：** 重写后只剩知乎、掘金、CSDN、简书、SegmentFault、开源中国 6 个技术社区。想顺带覆盖掘金、CSDN 可以看看，重写后的成熟度没有旁证。

## 四、内容生产

### 写作去 AI 味（写 skill 的素材）

最值得抄的四份：

| 资料 | 拿来干什么 |
|---|---|
| [MrGeDiao/shuorenhua](https://github.com/MrGeDiao/shuorenhua)（说人话） | 把「改稿边界」写成了可执行条款：哪些事实不能动、改多大范围、缺细节时怎么办，能直接当 skill 骨架 |
| [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh) | 改稿的优先顺序：先保信息和确定程度，再守文体，再像作者，最后才改表达；31 类 AI 腔 |
| [RobinZorro86/humanizer-zh-plus](https://github.com/RobinZorro86/humanizer-zh-plus) 第 34～38 条 | 中文特有的 AI 腔：四字词堆砌、文言虚词、中文排比、套路结尾、段落节奏太均匀，每条都有改写对照 |
| [KKKKhazix/human-writing](https://github.com/KKKKhazix/human-writing)（卡兹克） | 最狠的硬禁令：成稿不用冒号、破折号和「不是……而是……」；开头尽快碰到事情；每段必须带来新东西 |

另外两份值得看思路：liangjfblue/writer-dna 讲怎么从你的旧文章提炼出风格档案（仓库没写协议，只抄思路）；Raymondhou0917/speak-human-tw 提醒去 AI 味时最容易误加的「假人味」，比如说教腔、金句公式、假坦白。

合并去重后的 30 条规则在明细 [12 号文件](自媒体开源工具/12-中文去AI味与写作skill.md)，可以直接拿来用。其中第 3 条最关键：手上没有真实细节时，宁可写平实的陈述或者留占位符，也不能让 AI 编一个「具体数字」出来。

检测工具：腾讯朱雀对中文长文的实测表现不错，但官方没公布误判率；媒体实测过 10 款检测工具，误判、漏检都有。只能参考。

### 图文卡片、封面、配图

- 小红书、抖音图文卡片：Auto-Redbook-Skills 的排版脚本，改宽高就能复用到知乎配图、文章插图。
- 代码截图：freeze，单文件程序，有 Windows 版，能指定中文字体。Windows 下中文显示有两个没修的问题，先试一下。
- 流程图、时序图：mermaid-cli，一行命令出图。
- 文章里的示意图：baoyu-diagram，让 Claude 直接手写 SVG，不调生图模型，中文不会画错。
- 封面插画继续用你已有的生图 skill。
- 各平台图片尺寸都没有官方文档，第一次发之前在创作中心实测一下。

### 视频：不露脸技术教程

推荐流程，每一步都能让 Claude Code 调用：

1. **录屏：** Cap（2.3 万星，自带命令行和 MCP，专门为 AI 助手设计；主体是 AGPL 协议；Windows 11 上有一个录制中途崩溃、录像丢失的问题还没修）。求稳就用 OBS，它内置的远程控制功能可以让脚本开始、停止录制。想要录完自动跟着鼠标放大、加背景阴影的效果，用 OpenScreen 新仓库（getopenscreen/openscreen），原仓库已经归档。
2. **粗剪：** auto-editor，一条命令剪掉没说话的片段。
3. **字幕：** 有显卡用 VideoCaptioner 配 faster-whisper，自带 Claude Code skill，一条命令跑完转写、纠错、烧录（faster-whisper 官方测试：8GB 显卡上 13 分钟音频约 16 秒）。只有 CPU 用阿里的 SenseVoice，有 Windows 原生程序，不用装 Python。技术名词多的话，再加一步让大模型校对字幕。
4. **配音（可选）：** 想像自己的声音用 IndexTTS-2.5（B站开源，普通个人可以商用，但不能拿它的输出去训练别的模型）；想商用最干净用 VoxCPM2（代码和模型都是 Apache 协议）。两个都要 8GB 显存。只有 CPU 用 edge-tts（免费调用微软的在线语音，商用条款没查清）。fish-speech、F5-TTS 的模型不许商用，别用。
5. **成片：** 用 FFmpeg 脚本从同一份粗剪出横版（B站）和竖版（抖音、小红书）。
6. **讲解动画（可选）：** Remotion，官方自带 skill，个人和 3 人以内的公司免费商用，适合代码演示、架构图动画、60 秒讲解。讲算法用 Manim，配 manim-mcp 能让 AI 直接驱动（这个项目只有 20 星，要做好自己兜底的准备）。

别碰：MoneyPrinterTurbo、NarratoAI 用免费素材库拼画面，画面常常和文案对不上，正好是平台打击的低质搬运；Motion Canvas 已经停更；剪映自动化在新版剪映上失效（草稿被加密，要锁旧版本）；video-use 能跟 Claude Code 聊着剪片，但转写写死了只能用国外的付费服务，中文字幕会显示成方块。

## 五、选题与数据

- **追热点：** TrendRadar（6.3 万星），汇总 11 个平台的热榜，能按关键词过滤，自带 MCP，Windows 有一键脚本。
- **找选题：** 知乎官方「问题推荐」接口；再自建一个 RSSHub，把知乎热榜、B站热搜、GitHub 趋势榜、Hacker News、Product Hunt 串成订阅源交给 AI 读。公共服务已经被拦截，必须自建；知乎、小红书、抖音的订阅源反爬很严，B站最稳。
- **看评论找痛点：** B站用只读的 bilibili-mcp。
- **别碰：** MediaCrawler（6.6 万星，能抓的数据最全，但许可证只允许非商业学习用途，拿来获客就违反许可证）。

## 六、合规红线

1. **有 AI 参与就用平台的声明功能标出来。** 依据：《人工智能生成合成内容标识办法》第十条，2025-09-01 起施行。
2. **发布保留人工确认，别做全程托管。** 依据：小红书 AI 托管封号公告；微信公众平台运营规范 3.27 条。
3. **一个账号发，别用多个账号分发同样的内容。** 依据：抖音矩阵号治理规则；X 禁止多账号交叉发布相同内容。
4. **只克隆自己的声音。** 抖音 2026 年已处置 AI 肖像、声音类侵权内容 8.5 万条；B站的必剪要求实名认证、用本人录音才能克隆音色。
5. **不做、不传播去水印和去 AI 标识的工具或教程。** 依据：《标识办法》第十条，连「为他人提供工具」都禁止。

## 七、顺带提醒：你现有的公众号自动发布流程

微信公众平台运营规范新增了 3.27 条「非真人自动化创作行为」，官方原文已核实：不得利用 AI、脚本、接口等自动化方式替代真人完成内容创作、发布，具体包括「脱离真实创作者表达」的 AI 生成和改写，以及用脚本「批量、连续」发布。处罚是限流、删除，严重的封号。

你那条每天定时从素材库取图、自动生成标题简介、发公众号草稿（可选自动提交发布）的流程，落在这条的风险范围里。建议关掉自动提交发布，只生成草稿，人工确认后再发。原文没写「人工确认就不算」，最终由平台判断。

## 八、建议的落地顺序

1. **知乎（零成本，全是官方接口）：** 接上数据开放平台的官方 MCP 或 Skill，把「找问题 → 写 → 去 AI 味 → 预览 → 发布 → 回看数据」串成一条。
2. **去 AI 味 skill：** 用第四节那四份资料加 30 条规则写出来，所有平台共用。
3. **B站视频：** 录屏 → auto-editor → VideoCaptioner → biliup，先跑通一条不露脸教程。
4. **小红书、抖音：** 把同一份内容改成卡片和竖版视频，发布都留人工确认，先用小号试。
5. **X：** 最后再做。决定好接受按条付费还是半自动发布。
