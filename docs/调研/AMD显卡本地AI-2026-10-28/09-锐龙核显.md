# 09 锐龙核显和统一内存小主机

核验日期：2026-10-28。范围：ROCm 官方列出的 Ryzen APU/iGPU、本地 AI 系统入口；不做硬件实测、显存推算、速度或购买排名。

**结论：** ROCm 7.14.1 兼容矩阵按完整 APU 型号列名，不能把 gfx target 相同视为同系列全支持。Matrix 的 PyTorch/OS 支持也不等于任意模型、算子或应用均兼容。AI Max 的大容量统一内存只说明一种内存架构，不能单独推出默认分配量、推理效率或模型兼容性。[L09-S01]

## 系统与安装入口

ROCm 7.14.1 矩阵列 Ubuntu 26.04（GA kernel 7.0）、Ubuntu 24.04.4（OEM kernel 6.17）及 Windows 11 25H2；驱动行分别列 inbox kernel driver、Adrenalin 26.6.4、Windows OEM driver 26.10.28。框架表的 Ryzen Linux PyTorch 单元格列 2.12.0、2.11.0；Windows/WSL 对应行列 2.12.0，Python 行列 3.14、3.13、3.12、3.11。该固定版本的矩阵信息不是对每个核显型号、每个应用组合的额外认证。[L09-S01][L09-S09]

- **Linux 原生：** ROCm 7.1.1 Ryzen 安装页要求 Ubuntu 24.04 的 6.14 OEM kernel，安装示例使用 `amdgpu-install` 7.1.1，并以 `--usecase=rocm --no-dkms` 安装。页面还记录 gfx1151/AI Max 300 在特定 Ubuntu kernel 上的间歇问题。这是 7.1.1 页面步骤和限制，不应冒充 7.14.1 新版安装指引。[L09-S03]
- **Windows 原生：** ROCm 7.2 总览将 Ryzen APU 列为 Linux、Windows 上的 PyTorch 支持；7.1.1 限制页则明确当时 Windows 仅 PyTorch、仅 Python 3.12、无 ML training。后者是旧版限制，不外推为当前全局限制；Windows PyTorch 也不等于完整 ROCm stack。[L09-S02][L09-S04]
- **WSL 2：** ROCm 7.2 总览页的 WSL 条目当时写了 ROCm 7.2 与 Radeon RX 7700，没有列 Ryzen APU；这是该入口页的历史范围，不足以否定专用 WSL 路线。[L09-S02] AMD 专用 WSL 指南称 ROCDXG 于 Adrenalin 26.2.2 + ROCm 7.2.1 提供 production support，并首次支持 Ryzen Strix / Strix Halo SKU。[L09-S07] 固定版本的 librocdxg README 兼容表在 `1.2.0 + ROCm 7.2.x` 行明确列出 Ryzen AI Max+ 395、AI Max 390/385、AI 9 HX 375/370、AI 9 365。[L09-S08] 因此部分列名 Ryzen 型号已有官方 WSL 路线，不能扩展为所有 Ryzen iGPU 支持。指南列 Ubuntu 24.04/22.04，README 另列 Windows 11 与 Ubuntu 26.04/24.04/22.04；两处版本/系统条件分开记录，不拼成一组已验证组合。

## GPU、NPU 与内存边界

AMD 的 Windows ML 页面把 `VitisAIExecutionProvider` 对应到 Ryzen AI NPU，把使用 ROCm 的 `MIGraphXExecutionProvider` 对应到 AMD GPU。两条运行路线、软件栈和模型支持条件不同；NPU 可运行的模型不能据此算作 Radeon iGPU 的 ROCm 支持。[L09-S05]

**其他工具/社区可能入口：** AMD 发布过 Ryzen AI Max+ 395 的 llama.cpp ROCm/RPC 案例：四台 Framework Desktop、每台 128GB、Ubuntu 24.04.3，以 RPC 跑 Kimi K2.5 UD_Q2_K_XL（页面标为 375GB）。同一特定配置说明 BIOS dedicated VRAM 上限及 Linux TTM 参数可改变 GPU 可用量（页面给出最高 96GB BIOS、配置 TTM 后 120GB/节点）。这些数值是该机型/内核配置的原文，不是通用默认分配、单机模型承载承诺或性能证明；多机 RPC 案例也不能证明单台 128GB 可运行同一模型。[L09-S06] 本轮没有核验社区工具在 7840HS/8845HS 等未列型号上的兼容矩阵。

**未决与限制：** 本轮无硬件实测；应用、模型量化格式、插件、算子和具体 OEM BIOS/驱动组合仍需分别核对。专用 WSL 资料只确认所列 Ryzen Strix / Strix Halo 路线和 README 中明确列名的型号，其他 Ryzen APU 不因 gfx target 或核显名称而视为支持。
