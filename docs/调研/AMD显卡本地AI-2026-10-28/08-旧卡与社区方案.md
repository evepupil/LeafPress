# 08 旧卡与社区方案

核验日期：2026-10-28。范围：RX 580/590、Vega 56/64、Radeon VII、RX 5700/5700 XT、RX 6600/6700 XT 的 DirectML、ZLUDA、Windows ROCm/ComfyUI 社区路线。未安装、运行任何软件或驱动；无本机硬件实测。

## 结论与型号对照

目前能给出逐型号、带应用版本的正向社区实测只有 RX 5700 XT：一个用户报告在 Windows 的 comfyui-rocm 上用 ComfyUI 0.19.3、PyTorch 2.13.0a0+rocm7.13.0a20260423 完成 SDXL 提示任务。它是单一用户工作流，不构成官方支持或通用性能结论。DirectML 只证明 DirectX 12/torch-directml 软件入口，未找到本表任一型号与具体 AI 应用版本的配对证据。上游 ZLUDA FAQ 泛称 RX 5000 系列及更新款，明确排除 Vega；这不是 ComfyUI 逐卡认证。旧 ComfyUI-Zluda 文档另有 RX 400–500 系列旧路径，不能等同于当前上游 ZLUDA 支持。

## 入口、版本与边界

- DirectML 项目 README 明示处于 maintenance mode；torch-directml 是 PyTorch 插件，文档列 Python 3.8–3.12 和 Windows/WSL 安装入口。已打开的 GitHub release 页面版本为 torch-directml 0.2.4.dev240815（2024-08-19），其算子更新记录反而说明应用/算子覆盖须按版本核验。它不证明 ComfyUI、其他 AI 应用或某张卡可用。[L08-S01–L08-S03]
- ZLUDA 上游 FAQ 写明 RX 5000 系列及更新款、排除较旧 Polaris/Vega 消费卡 [L08-S04]。Quick Start 的 ReadTheDocs 链接本轮未复核，不据此增加安装保证 [L08-S05]。已见最新 release 为 v7-preview.19（2026-10-26），属于仍在开发的软件，不是任意 CUDA 应用兼容承诺。[L08-S06]
- 社区入口：[ComfyUI-Zluda](https://github.com/patientx/ComfyUI-Zluda) 的 README 提到 RX 400–500 Series / HIP 5.7.1 旧路线，并在 2026-03-19 更新段提到 ZLUDA 3.9.5 nightly；没有给出目标显卡逐型号、ComfyUI 版本与成功工作流的完整矩阵。[L08-S07]
- [comfyui-rocm](https://github.com/patientx-cfz/comfyui-rocm) 自述覆盖 GCN5/Vega、RDNA1–4；所见 release `101026` 发布于 2026-10-10。此为社区打包/安装器的范围声明，不是 AMD ROCm 官方兼容承诺。Vega 56/64 的实际 issue 与宽泛支持标签存在明显落差。[L08-S08][L08-S09][L08-S11][L08-S12]
- 独立层次不可混写：显卡在 Windows 驱动中可识别，不等于 HIP/ROCm 可枚举；HIP/DirectML 可枚举，也不等于 PyTorch 算子、ComfyUI 版本、节点和模型都可运行。Issue 中用户自报驱动版本不构成 AMD 官方驱动支持证据。

## 缺口

本轮未能打开 AMD 按型号驱动支持页面，也未能核验 Microsoft Learn 与 ROCm 官方兼容矩阵；因此各卡的当前 AMD 驱动支持、驱动版本/操作系统组合均为未知。DirectML 缺每张卡对应的具体应用及版本实测；RX 580、RX 590、Radeon VII、RX 5700 缺逐卡社区成功日志；RX 6600 的安装失败报告没有完整软件版本。RX 6700 XT 的社区日志存在版本与手工修改差异，不能据此归纳为稳定支持。上述未知不代表硬件必然不能运行。
