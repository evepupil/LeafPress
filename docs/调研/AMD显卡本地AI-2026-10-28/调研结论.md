# 截至 2026 年 10 月，AMD 显卡跑本地 AI：调研结论

核验日期：2026-10-28，时区 Asia/Shanghai。用途：为文章准备可追溯的事实、型号表和写作边界。本轮只查公开文档、发布资产和社区记录，没有安装驱动、运行模型或测试硬件。

## 核心判断

这个题目值得写。读者真正需要的是：手里的显卡能从哪条路线开始；准备买卡时，有哪些软件、系统和版本条件需要先确认。

AMD 跑本地 AI 已有多条公开入口，包括原生 Windows、原生 Linux、WSL，以及 llama.cpp、Ollama、ComfyUI 等工具。但这些入口的显卡名单、驱动、框架版本不同。**一张通用的“AMD 支持显卡清单”不足以回答读者的问题，文章需要同时写清具体型号、操作系统和应用。**

目前资料对部分 RX 7000、RX 9000 和 Ryzen AI Max 型号的覆盖较充分。RX 6000 和更早显卡也有工具入口或社区案例，但不能因此写成各应用都已验证可用。本轮也不足以给出速度、稳定性、功耗或性价比排名。

## 按软件选择路线

### llama.cpp：需要分别看 Vulkan 和 HIP

llama.cpp 的官方构建资料和发布资产提供 Vulkan、HIP/ROCm 等入口。Vulkan 是理解“未在 AMD ROCm 官方名单里，仍可能跑本地大模型”的关键。它也有最低 Vulkan 功能、驱动和具体算子的要求。

编译清单中出现某个显卡架构，只说明构建覆盖该目标，不能当成每张卡均已测试。Linux 的架构覆盖变量也不能直接照搬到 Windows。文章建议链接官方构建文档和发布页，不把远程脚本的下载即执行命令作为安装建议。

依据：[04 调研](04-llama.cpp推理.md)。

### Ollama：Windows 和 Linux 的名单分开看

当前所核官方文档的 Linux ROCm 名单包含部分 RX 6000、7000、9000；Windows ROCm 名单不同。Windows 文档同时提供 Vulkan 补充入口。当前文档写明已安装的 Vulkan 后端默认启用，但这不构成全部 AMD 卡、全部模型的稳定性承诺。

RX 6600 的历史 Windows + ZLUDA 记录，应保留当时软件版本和后端名称，不能用来下当前原生 ROCm 的绝对结论。

依据：[05 调研](05-Ollama推理.md)。

### ComfyUI：三种安装入口分开写

本轮确认有 Windows AMD 便携包、桌面版环境定义和手动安装文档。所见手动 Windows 路线使用 ROCm 10.0 多架构 PyTorch 包；Linux 手动路线、便携包构建配置、桌面版环境定义的版本各自不同。

文章不能把旧 AMD PyTorch 7.2.1 专项页里的 Python、框架和训练限制，直接套到当前 ComfyUI 手动安装路线。也不能把官方安装入口扩成所有自定义节点、模型和工作流兼容。桌面版实际随包版本和便携包实际运行结果，本轮未实装确认。

依据：[07 调研](07-ComfyUI生图.md)、[02 调研](02-Windows官方支持.md)。

### vLLM：有独立的硬件和内核要求

vLLM 官方 AMD 文档点名的硬件范围、Linux 和 Python 要求、发布包、量化内核条件需要单独核对。统一 ROCm 矩阵列入某张卡，不能据此推断 vLLM 对该卡的所有模型和量化方式提供支持。

依据：[06 调研](06-vLLM推理.md)。

## 版本资料的处理原则

1. **优先保留完整出处和适用版本。** 当前统一 ROCm 文档与旧 Radeon/Ryzen 7.2.1 专项文档属于不同发布阶段；旧页仍能打开，不代表其中的名单和安装命令就是当前全貌。
2. **按显卡家族读取动态表。** AMD 统一矩阵会按显卡家族和系统过滤单元格。主会话实查发现，ROCm 10.1.0 的 Radeon/Ryzen Linux PyTorch 单元格列 2.14.0；同一行对 Instinct 列的 2.13、2.12 不能抄过来。固定版 7.14.1 的 Radeon/Ryzen Linux 单元格列 2.12.0、2.11.0，也不能加入 Instinct 列的 2.10。见[筛选条件核验](矩阵筛选条件核验.json)。
3. **WSL 新旧路线分别列出。** 旧 ROCm 7.2 / Adrenalin 26.1.1 矩阵，与新 ROCDXG / Adrenalin 26.2.2 路线不能拼接。本轮没有建立新路线的完整框架版本组合；监控工具的具体指标也需要区分版本。
4. **社区证据保留上下文。** 一个成功案例必须带型号、系统、应用版本和实际运行内容；安装器显示“支持”不等于模型已跑通。没查到证据时保留未知。

## 建议的文章结构

建议题目：《截至 2026 年 10 月，AMD 显卡跑本地 AI：哪些型号能用，Windows 和 Linux 怎么选》。

1. 开篇先给“已有硬件查入口”表，明确无硬件实测。
2. 分本地大模型、ComfyUI 两种用途，解释各应用当前入口。
3. 分 Windows、Linux、WSL，列可核对的版本条件，不放混搭命令。
4. 单独处理 RX 6000、老卡和 Ryzen AI Max；说清哪些是官方列名，哪些只有社区案例。
5. 给出核验日期、来源和未解决问题，保留可持续更新的资料底表。

发布前优先补充的证据：选定一张目标显卡，完整跑通一个大模型和一个 ComfyUI 工作流；记录实际驱动、应用和模型版本。性能比较需要另设测试，不能从本调研的支持名单推出。
