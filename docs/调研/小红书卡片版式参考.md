# 小红书卡片版式参考

> 调研日期：2026-10-18 · 用途：给 [平台适配 · 小红书](../模块设计/平台适配-小红书.md) 重新设计卡片样式 · 做法：六路侦察分头查（知识类账号、封面规律、开源模板、模板平台、技术内容上卡片、海外知识轮播图），主控另外看了 8 张开源项目的真实样张。小红书站内要登录才能看，按约没有登录，账号层面的结论都来自公开的拆解文章。

## 结论

1. **现在的毛病被直接点名**：标题挤在上方、下半张空着，在两列信息流里缩成小图后看不清。好几份资料把它列为反面例子（michelle-cover 的风格规范、海外轮播图指南）；歸藏的规范也写了「下半张空了就合并页面，或者加清单、对比行、金句这类有用的元素」。
2. **封面**：
   - 标题区占画面四到六成，放在视觉中心附近；
   - 标题 6～14 个字、最多 3 行；1080 宽的卡上至少 96px，激进做法到 150～180px；
   - 只有一个视觉焦点；关键词只点一处（色块、下划线或换色），数字放大并换成强调色；
   - 文字和底色对比度至少 4.5:1。
3. **内页**：
   - 一页一个观点，标题加 2～4 条；
   - 标题和正文字号大约 2:1（标题 60～72px，正文 36～44px），行高正文 1.4～1.6、标题 1.2～1.3；
   - **字少就放大**；条数少时用大号编号、金句块、对比行把版面撑起来，不留大片空白。
4. **系列感**：每页固定位置放系列名或期号、页码、账号名；整套只用一个强调色。读者翻两三页就知道去哪找信息。
5. **颜色**：最多三个（底色约六成、文字约三成、强调色约一成）；不用纯黑纯白；强调色只给重点，不做大面积底色。
6. **字体**：本机装有思源黑体（Noto Sans SC）、思源宋体（Noto Serif SC），都是开源可商用；等宽字体有 Cascadia Code。现在用的微软雅黑不是开源字体，商用有风险，改用思源。
7. **开源模板大多也有空白问题**，而且常把「换个颜色」算作一种风格：flyanx 的 20 种风格里大半只是换色。上一轮我们出的四套样张也是这个错。

## 三个候选方向

三个方向的区别在**版式**上，颜色只是附带。每个方向都要出封面、条数少的要点页、条数多的要点页三张，放在一起看。

> 作者的取舍（2026-10-18）：看了参考样张后挑出 Flyanx 的封面（对应 B）和「灵感记」备忘录风（下文「没选进候选的」里那个），A、C 不做。方向图见 [平台适配 · 小红书](../模块设计/平台适配-小红书.md) 的「待作者定」。

### A 大字报

- **借鉴**：模板平台成套的大字报封面、海外轮播图的「大字宣言」封面、妈的欧洲账本的纯色底大字。
- **赌的是**：信息流里第一眼最显眼，缩成小图也能看清标题。
- **封面**：标题铺满上中部，150～180px 粗黑体、左对齐、最多 3 行，占画面五到六成；关键词压一块强调色色块；左上小字系列名，底部账号名和「共 N 页」。
- **内页**：左上一个超大编号（01、02……，强调色）；标题 64px，条目 44px；条数少时字号放大、条目间距拉开。
- **颜色**：暖白底 #F6F4EF、近黑字 #151515、强调黄 #FFD43B（做色块）。
- **风险**：容易显得像营销号，也容易和大量同类撞脸。

### B 杂志编辑

- **借鉴**：烛章系列卡（白纸面、左上固定编号、右上固定短标题）、稿定社区的心理学科普系列（顶部标签 + 大标题 + 底部金句）、歸藏的编辑风（细线、一个强调色、一页一个刊号元素）。
- **赌的是**：像一本认真做的小册子，显得专业、值得收藏，和「一叶之桐」在知乎写长文的调性一致。
- **封面**：顶部一行刊头（系列名 · 第几期，下面一根细线）；标题用思源宋体粗体 120～140px，放在画面中部，占四成多；副标题一行；底部一句金句。
- **内页**：固定页眉（左「02 / 06」、右短标题、细线）和页脚（账号名）；标题 60px；条目带 ①②③ 和细分隔线；条数少时条目放大、在版面里均匀铺开，最后加一块浅底的「一句话」。
- **颜色**：纸白 #FAF8F3、墨色 #23211E、一个强调色（赭红 #B5482F）。
- **风险**：在信息流里没有大字报那么扎眼，更依赖标题文案本身。

### C 终端

- **借鉴**：kylinzhao 的暗色 Linear 卡、lieflat 终端模板、Carouselr 的代码页规则。
- **赌的是**：一眼看出是写代码、做 AI 的人发的，吸引对口的读者。
- **封面**：深色底，中间一个终端窗口（左上三个圆点、文件名栏），窗口里 `$` 提示符加大号白字标题（120～140px），关键词用亮绿；底部 3～4 个话题小标签。
- **内页**：窗口框贯穿每页；页眉用等宽小字「step 02 / 06」；条目前用 `→`；代码和命令用等宽字体单独成块；条数少时内容在窗口里垂直居中、字号放大。
- **颜色**：深底 #0F1115、正文 #E6E8EB、亮绿 #4ADE80。
- **风险**：认知科学、经济管理这类非编程话题套上终端框会别扭；深色卡片在以浅色为主的信息流里偏重。

### 没选进候选的

- **手帐网格纸**：手写体的调性和技术内容冲突。
- **备忘录**：偏情绪和语录，技术内容用它显得轻。
- **仿聊天界面**：适合问答式内容，以后可以作为一种页型加进来，不单独成为方向。

## 不管选哪个都要改的

1. 封面标题放大，移到视觉中心附近，标题区占四到六成。
2. 内页按内容多少自动调字号和间距，条数少时用大号编号或「一句话」块撑起版面。
3. 每页固定页眉页脚：系列名或期号、页码、账号名。
4. 卡片稿里能标出要强调的关键词（比如 `==关键词==`），封面和内页用同一种强调。
5. 字体换成思源黑体和思源宋体，等宽用 Cascadia Code。

## 没查清的

- 小红书站内要登录，账号层面没看到原图，只有二手文字描述。
- 信息流小图的实际显示宽度没有实测数字。
- 封面字号下限各家说法不一（60pt 到 180px），以出图后缩到手机尺寸实看为准。
