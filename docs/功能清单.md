# 功能清单

> 状态：已定稿 · 最近更新：2026-10-05 · 上游：[需求设计](需求设计.md) · 下游：[roadmap](roadmap.md)

编号写进文档后固定不变，技术、架构、roadmap 都用编号引用。状态只用三个词：要、不要、以后做。

## 1 一稿多用

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 1.1 | 原稿读取 | 先把博客仓库拉到最新，再读出文章的元数据、正文和图片 | 要 |
| 1.2 | 发布状态总览 | 列出每篇原稿在各个平台、各种形态下的发布情况 | 要 |
| 1.3 | 知乎文章版改写 | 按知乎的写法改写，规则来自知乎写作 skill 和去 AI 味规则 | 要 |
| 1.4 | 知乎回答版改写 | 找到相关问题让作者选，把开头改成回答这个问题的口吻 | 要 |
| 1.5 | 固定转换 | 流程图转图片、站内链接补成完整网址、文末附博客原文链接 | 要 |
| 1.6 | 禁用句式检查 | 按规则文件找出可疑句子，标给作者看 | 要 |
| 1.7 | 交给知乎官方 skill 发布 | 由官方 skill 传图、转格式、预览、发布，发完取回链接 | 要 |
| 1.8 | 复制页 | 生成能直接复制粘贴的回答成品页，带直达问题页的链接 | 要 |
| 1.9 | 知乎想法版 | 短帖形态，原稿压成几句话加配图 | 以后做 |
| 1.10 | 小红书图文卡片 | 原稿生成一套卡片图和文案，作者手动发 | 以后做 |
| 1.11 | 视频形态 | 视频母版生成 B站横版、抖音竖版等版本 | 以后做 |
| 1.12 | 改稿差异学习 | 保存作者改稿前后两版，定期把常改的地方写回规则 | 以后做 |

## 2 选题与素材

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 2.1 | 素材收集 | 扫指定项目上次之后新增的进度记录、review 记录、提交记录 | 要 |
| 2.2 | CloudMind 记忆接入 | 由 skill 取近期记忆，并入素材 | 要 |
| 2.3 | 题单 | 把素材归成候选题，每题附来源和平台上对得上的问题 | 要 |
| 2.4 | 随手记 | 一句话进素材池，附上当前项目和时间 | 要 |
| 2.5 | 知乎问题搜索 | 调知乎数据开放平台搜问题、拿推荐问题 | 要 |
| 2.6 | 采访式写稿 | AI 根据素材提问，作者回答，整理成稿 | 要 |
| 2.7 | 写入博客原稿 | 按博客规矩写中英双语文章，过博客门禁后提交 | 要 |
| 2.8 | 会话记录作素材 | 从 Claude Code 和 Codex 的会话记录里挑素材 | 以后做 |

## 3 记录与数据

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 3.1 | 本地记录库 | 存作品、原稿、资产、版本、发布、素材、题目、工作流进度 | 要 |
| 3.2 | 发布登记 | 接口发布自动登记；手动发布由作者回填链接 | 要 |
| 3.3 | 平台数据回看 | 定期拉阅读、赞同等数据，按选题类别汇总 | 以后做 |
| 3.4 | 本地网页工作台 | 素材池、题单、发布记录放在一个页面里看 | 以后做 |

## 4 工程与扩展

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 4.1 | 平台接入框架 | 统一接口：支持的形态、限制、转换、发布方式、拉数据 | 要 |
| 4.2 | 工作流框架 | 步骤编排，能停在 AI、确认、交接、手动这几类步骤上，之后接着跑 | 要 |
| 4.3 | 配置与凭证 | 本地配置文件；复用知乎官方的共享凭证文件 | 要 |
| 4.4 | skill 套件与安装 | LeafPress 的 Claude Code skill，一条命令装到用户级 skill 目录 | 要 |
| 4.5 | 体检命令 | 检查配置、博客仓库、凭证是否齐全、浏览器能否启动，不输出密钥 | 要 |
| 4.6 | 模拟浏览器发布 | 给没有接口的平台用；账号风险高，用之前单独评估 | 以后做 |
| 4.7 | 定时自动运行 | 题单在作者问的时候再生成，够用 | 不要 |
