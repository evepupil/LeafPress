# 功能清单

> 状态：已定稿 · 最近更新：2026-10-19（灵感一节按作者确认的 M4 补全） · 上游：[需求设计](需求设计.md) · 下游：[技术设计](技术设计.md) · [架构设计](架构设计.md) · [roadmap](roadmap.md)
>
> 这一版按「个人全栈自媒体工作台」重写，页面和区块以网页原型的规格为准（`web/DESIGN.md`、`web/design/*.md`），不另写页面清单。旧版在 git 历史里。

编号写进文档后固定不变，技术、架构、roadmap 都用编号引用。状态只用三个词：要、不要、以后做。

## 1 作品与任务

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 1.1 | 作品看板 | 四列：待实现（按先后排队）、进行中、等你处理、已完成；已完成先显示一部分 | 要 |
| 1.2 | 作品列表 | 按状态分组的表格，和看板共用筛选 | 要 |
| 1.3 | 平台筛选和搜索 | 按平台筛，按标题、要求、编号搜 | 要 |
| 1.4 | 拖动换列和排先后 | 拖到待实现、等你处理、已完成改状态，在待实现里拖动排先后；进行中只由 agent 接手，网页上不能拖进去；手机上用卡片菜单 | 要 |
| 1.5 | 作品详情可编辑 | 标题、要求、工作流（还没开始时）、链接、挂的问题 | 要 |
| 1.6 | 新建作品 | 直接新建，选几个账号生成几个作品 | 要 |
| 1.7 | 转作品 | 灵感或已发作品选平台，一转多，工作流按平台和来源自动配 | 要 |
| 1.8 | 等你处理面板 | 通用的「要你做的事」加反馈框，提交后回到待实现最前面 | 要 |
| 1.9 | 步骤和记录 | 详情里看工作流每一步的状态、产出文件、作品的记录 | 要 |
| 1.10 | 任务文件夹 | 每个作品一个文件夹，说明文件跟着记录库自动更新，产出由 agent 写进来 | 要 |
| 1.11 | 复制给 AI | 复制一个作品的完整说明，最后附整份账号档案 | 要 |
| 1.12 | 删除作品 | 删前确认；任务文件夹留着 | 要 |
| 1.13 | 自动刷新 | agent 在命令行改了状态，网页几秒内跟着变 | 要 |
| 1.14 | 「让 AI 做」按钮 | 在网页上一键让 AI 做 | 不要 |
| 1.15 | 打开任务文件夹 | 详情里一键在资源管理器里打开（只在本机能用） | 要 |

## 2 灵感

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 2.1 | 随手记 | 一句话进收件箱，可挂到账号；快捷键 N、手机右下角按钮 | 要 |
| 2.2 | 灵感看板 | 收件箱、值得写、已转作品三列，能拖、能点开编辑 | 要 |
| 2.3 | 灵感转作品 | 选平台一转多，灵感挪到已转作品并记下作品 | 要 |
| 2.4 | AI 批量写灵感 | agent 用命令行一次加多条，带来源 | 要 |
| 2.5 | 跑灵感 | 每天早上往收件箱放 5～10 条：代码找候选、去重、排序，AI 挑出来写清来源、为什么值得写、建议角度、相关作品；codeg 自动任务每天跑（2026-10-19 改为要，CloudMind 不做） | 要 |
| 2.6 | 知乎找问题 | 开放平台按账号画像、按主题词推荐问题，热榜里挑命中主题词的，补已有回答的摘要 | 要 |
| 2.7 | 已发作品续写 | 数据好的作品提成续写或换平台再发的选题 | 要 |
| 2.8 | 开发记录选题 | 各项目近 7 天的提交和进度流水提成选题 | 要 |
| 2.9 | 不重复推 | 同一个问题不进两次，删掉的不再推，没挑中的 14 天后再看 | 要 |
| 2.10 | 越用越准 | 常转成作品的方向多推，常删的少推 | 以后做 |
| 2.11 | AI 圈热点 | 模型发布、工具更新、GitHub 热门项目 | 以后做 |

|---|---|---|---|

## 7 平台：博客

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 7.1 | 导入已有文章 | 博客仓库里的中文文章一次导入成已完成作品，带链接和本地路径；英文版不单独成作品 | 要 |
| 7.2 | 博客写稿工作流 | 整理素材 → 写中文稿 → 写英文稿 → 跑博客门禁 → 提交推送 → 归档链接；推送前不设确认（用户定） | 要 |
| 7.3 | Umami 数据 | 用 Umami 共享链接拉访问、访客：全站每天的数、每篇文章累计的数（只看中文版的地址）；第一次接上时补最近半年 | 要 |
| 7.4 | 博客账号配置 | 仓库路径、站点地址、Umami 共享链接（按密钥存） | 要 |

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
