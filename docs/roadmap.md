# LeafPress roadmap

> 当前进度：M0 已完成，M1 底座进行中（2026-10-09 开工，模块设计已写完）。定位调整为「个人全栈自媒体工作台」，网页原型已获认可（[网页 · 原型](模块设计/网页-原型.md)、[前端设计](前端设计.md)）；按新定位重写了需求、功能清单、技术和架构设计，里程碑重排成先做底座、再按平台一个一个接（2026-10-08）

## 目标

做一个跑在本机的个人自媒体工作台：灵感转成各平台的作品任务，agent 用命令行接手、按工作流做，要人动手时停下来等作者，数据每天自动拉回来客观地看。先把底座和通用流程做通，再按平台一个一个接：每个平台包括作品产出的工作流、数据获取的工具和这个平台账号要配的东西，顺序是博客 → 知乎 → 小红书 → B站。设计见 [需求设计](需求设计.md)、[功能清单](功能清单.md)、[技术设计](技术设计.md)、[架构设计](架构设计.md)。

## 里程碑与分层

### M0 地基

旧定位下的地基，代码在新架构的 [分层](架构设计.md#分层) 里归到存储和基础两层，M1 改造后沿用。

### M1 底座

涉及 [总体结构](架构设计.md#总体结构) 里除定时任务和手机以外的全部框：网页、本机服务、命令行、用例、共享规则、平台适配里的通用工作流、数据目录；[数据模型](架构设计.md#数据模型)；[一个作品从灵感到归档](架构设计.md#一个作品从灵感到归档)；[状态流转](架构设计.md#状态流转)；[agent 和命令行怎么配合](架构设计.md#agent-和命令行怎么配合)；[出错与恢复](架构设计.md#出错与恢复)。

### M2 博客

涉及 [分层](架构设计.md#分层) 里平台适配的博客目录、[每天拉数据](架构设计.md#每天拉数据)、总体结构里的 Windows 计划任务。

### M3 知乎

涉及平台适配的知乎目录；[一个作品从灵感到归档](架构设计.md#一个作品从灵感到归档) 里的复制页和「你去投递」。

### M4 灵感自动化

涉及 [扩展点](架构设计.md#扩展点) 的「定时跑灵感」、总体结构里的 AI 定时任务。

### M5 小红书

涉及 [扩展点](架构设计.md#扩展点) 的「新平台」：平台适配加小红书目录，卡片出图用本机 Edge。

### M6 B站

涉及 [扩展点](架构设计.md#扩展点) 的「新平台」：平台适配加 B站目录，视频处理和投稿调外部命令行。
