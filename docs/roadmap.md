# LeafPress roadmap

> 当前进度：M0 进行中（2026-10-05）

## 目标

做一个跑在本机的个人内容工作台：从日常开发里收素材、出题单，把一份原稿改成多个平台、多种形态的版本，发布前由作者确认，并记下每次发布。先打通博客和知乎的文字内容，再按同一套平台接入扩到小红书和视频平台。设计见 [需求设计](需求设计.md)、[技术设计](技术设计.md)、[架构设计](架构设计.md)。

## 里程碑与分层

### M0 地基

涉及 [内容模型](架构设计.md#内容模型)、[分层](架构设计.md#分层) 里的记录库、配置、命令行，以及 [平台接入](架构设计.md#平台接入) 和 [工作流](架构设计.md#工作流) 的框架部分；博客接入只做读取。

### M1 转知乎文章

涉及 [主流程 · 转写](架构设计.md#主流程)、[发布方式](架构设计.md#发布方式) 里的「交给 skill」、知乎接入的长文形态，以及 skill 层。

### M2 转知乎回答

涉及知乎接入的回答形态、[发布方式](架构设计.md#发布方式) 里的「手动成品」。

### M3 题单与写稿

涉及 [主流程 · 题单](架构设计.md#主流程)、素材收集、博客接入的写入、[发布方式](架构设计.md#发布方式) 里的「写 git 仓库」。

### M4 小红书图文卡片

涉及新平台接入、[内容模型](架构设计.md#内容模型) 的图文卡片形态、资产处理里的卡片渲染。

### M5 数据回看

涉及平台接入的「拉数据」和记录库的数据快照，见 [扩展点](架构设计.md#扩展点)。

### M6 视频平台

涉及视频母版原稿、资产处理里的视频部分、[发布方式](架构设计.md#发布方式) 里的「外部命令行」，见 [扩展点](架构设计.md#扩展点)。

### M7 本地网页工作台

只读记录库的新一层，见 [扩展点](架构设计.md#扩展点)。开工前先写 `docs/前端设计.md`。
