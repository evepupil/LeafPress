# 前端设计

- 一句话视觉方向：照搬 DeverDesk 的安静工作台：窄导航、宽工作区、13px 小字号、浅灰到白的三级底色，颜色只用来识别平台和状态，数字一眼可读。
- 参考来源：
  - DeverDesk（用户自己的项目，`C:\code\DeverDesk`，规格见它的 `docs/前端设计.md`）：令牌、外壳、shadcn 组件、看板列、白卡、主图卡、周回顾页，几乎原样沿用；
  - Linear（凭记忆）：32px 列表行、整行悬停变浅灰、属性用小标签；
  - 知乎创作中心「内容分析」、B站创作中心「数据中心」（凭记忆）：单篇数据表的列（阅读、赞同、收藏、评论、近 7 天）；
  - 新榜（凭记忆）：多账号横着比粉丝、增减、发布数；
  - GitHub Projects、Trello（凭记忆）：拖卡片换列、列内拖动排先后、拖动时画一条插入线。
- 对应代码：`web/`（令牌 `web/src/styles/tokens.css`，工具类映射 `web/src/app/globals.css`，组件 `web/src/components/`，外壳 `web/src/features/shell/`，各页 `web/src/features/<页面>/`）；逐区块规格在 `web/DESIGN.md` 和 `web/design/*.md`。
- 当前状态：可点击原型第二版。7 个页面（作品、灵感、账号、账号详情、工作流、数据、周报），作品页是首页；作品和灵感能改、能拖、能转，改动存在浏览器里（刷新不丢，头像菜单可恢复初始数据），数据快照仍是写死的演示数据；只有浅色主题。
- 最近更新：2026-10-08
- 实现它的模块文档：[网页 · 原型](模块设计/网页-原型.md)

视觉方向这次没有另出示意图挑选：用户明确要求「照 DeverDesk 的风格」，DeverDesk 的视觉在它自己的前端设计文档里已经定稿并落地，这里沿用它的令牌和组件，只补自媒体工作台特有的平台标识和数据图。

### 字号、字重、间距、圆角、阴影

| 项 | 值 |
|---|---|
| 字族 | Inter Variable，中文回落系统黑体；等宽 `ui-monospace, SF Mono, Cascadia Mono, Consolas` |
| 字号 | 12/16（辅助、表头、标签）、13/17（正文，默认）、20/24（主图卡页签和账号详情的粉丝数）；不用别的字号。例外：输入框在手机上用 16px（shadcn 的默认写法，防止 iOS 聚焦时自动放大），`md` 起回到 13px |
| 字重 | 400、500 两档 |
| 骨架 | 窗口栏 38px、侧栏 240px、视图栏 40px、筛选栏 40px |
| 间距 | 4px 基准；卡片间 8px；卡片内边距 12×10 或 16×12；列表行高 32px、表格行高 36px |
| 圆角 | 控件 5px、卡片 6px、弹窗 8px、标签 3～4px |
| 阴影 | 卡片 `0 1px 1px rgb(16 16 24 / .03), 0 1px 3px rgb(16 16 24 / .035)`；浮层 `0 8px 24px rgb(16 16 24 / .08), 0 2px 6px rgb(16 16 24 / .04)`；弹窗 `0 16px 48px rgb(16 16 24 / .14), 0 4px 12px rgb(16 16 24 / .05)` |

## 明暗主题

只有浅色主题。暗色主题没有做：DeverDesk 本身也只有浅色，令牌文件里语义变量都已经集中，要做暗色时只在 `tokens.css` 加一组 `.dark` 下的值。

## 布局与响应式

- 外壳：38px 窗口栏（前进后退、居中搜索、提醒、头像）→ 240px 侧栏（页面、账号、视图三组）+ 右侧近白工作区面板，面板右下留 8px。
- 工作区：40px 视图栏（页面名 + 视图页签 + 动作）→ 可选 40px 筛选栏 → 可滚动内容，内容外边距 12px。
- 断点：`lg`（1024）以下侧栏收进左侧抽屉，右下角出现「记灵感」圆形按钮；`md`（768）以下多栏网格变一列；宽表格一律放进横向滚动容器。
- 验收两档：桌面 1440×900、手机 390×844。

## 空态、加载态、错误态

- 空态：一枚 20px 细线图标（`#8f8f98`）+ 一句话 + 至多一个动作按钮，居中，上下各留 32px。文字只说现状，例如「这周还没有发布」「没有符合条件的作品」。
- 加载态：页面脚本就绪前画外壳骨架（灰块 + 看板列灰底），不闪白。原型的数据都是本地的，区块内没有加载态；「AI 正在做」用唯一的循环动画——转圈图标。「现在跑一次」「现在拉一次」这类按钮点了先禁用并转圈约 1 秒，再出提示条。
- 「等你处理」的强调：只用卡片边框的进度黄和 12～13px 的警示黄小字（`#8a6100`），不铺黄色底块；详情抽屉最上面的「要你做的事」面板同样只有黄边框。
- 错误态：空态同样的版式，图标换成红色，文字说清楚错在哪。数据拉取失败这类业务错误用红色小字加修复提示，不弹窗。

## 动效

- 只有颜色过渡：`120ms`（`--dur-fast`）和 `160ms`（`--dur-base`），缓动 `cubic-bezier(0.2, 0.7, 0.3, 1)`。
- 弹窗、抽屉、下拉用 shadcn 自带的淡入和滑入。
- 不做入场动画、数字滚动、悬停放大；图表不做入场动画。系统设置了减少动效时全部关掉。

## 无障碍底线

- 正文对比度 ≥ 4.5:1（正文 16:1、次要文字 5.9:1）；`#8f8f98` 只给图标和占位，不做正文。
- 全部可交互元素能用键盘到达，焦点可见；图标按钮带文字说明（读屏和悬停提示）。
- 图表带 `aria-label`，纯装饰的图形 `aria-hidden`；状态图形带读屏文字（「已发」「等你处理」）。
